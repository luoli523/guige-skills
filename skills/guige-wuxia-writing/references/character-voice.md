# 金庸写作风格卡·人物专属语言系统

本模块由 `SKILL.md` 按任务类型加载；人物的信息权限与感知中心见 `viewpoint-distance.md`，本名、法号、绰号、官称和化名的生成与变义见 `naming-and-semantic-networks.md`。

## 一、核心结论

人物声口不是几个口头禅，也不只是“古雅、粗鲁、聪明、老实”等形容词，而是一个动态生成系统：

```text
稳定性格
＋知识边界
＋关系位置
＋当前说话目的
＋情绪压力
＝这一次具体怎样说
```

真正稳定的不是人物每次都说同一种句子，而是：

- 他习惯先注意什么；
- 他怎样理解别人；
- 他愿意承认什么；
- 他会隐瞒什么；
- 他用什么方式取得主动；
- 压力升高时，他的语言怎样变形。

AI塑造声口时，应复制“生成规则”，而不是机械重复标志词。

- 郭靖近半对白不超过十字；周伯通平均长度约为郭靖三倍。

- 穆念慈的省略与中断显著，反映情感难以完整说出。
- 梅超风对白中位长度最短之一，但问句密集，多为逼问、质问和挑战。

## 三、人物声口的五层模型

### 第一层：注意力偏好

人物开口之前，先决定他在当前场面首先注意什么。

| 人物类型 | 优先注意 |
|---|---|
| 质朴守信者 | 承诺、事实、谁需要帮助 |
| 机敏谋划者 | 破绽、动机、可利用的话语空间 |
| 江湖领袖 | 局势、规矩、众人安危 |
| 孤傲宗师 | 身份、能力、是否受辱 |
| 利己谋士 | 利害、筹码、退路、信息差 |
| 道德刚烈者 | 是非、荣辱、忠奸、是否守约 |
| 情感压抑者 | 对方态度、关系裂缝、不敢直说的事 |

不同人物即使回答同一问题，也应先处理不同的信息。

### 第二层：知识边界

每个人都应有四类知识：

```yaml
knows: 真正熟悉，可以自然调用
half_knows: 听说过，会说但可能误解
does_not_know: 无法理解或不会使用
misbelieves: 深信但错误的判断
```

声口差异经常不是词汇差异，而是“这个人物根本不会想到那个角度”。

禁止让作者知识自动流入所有人物。

### 第三层：关系语域

人物面对不同对象时，会改变：

- 称谓；
- 自称；
- 礼貌程度；
- 句子完整度；
- 是否解释理由；
- 是否暴露真实感情。

例如同一人物可能同时拥有：

```text
对师父：恭敬、少辩解
对爱人：亲昵称谓、话说一半
对晚辈：命令或调侃
对同辈高手：客气中争胜
对敌人：讥刺、试探、拖延
对陌生人：身份化自称与礼语
```

人物不是只有一种口吻，而是在关系矩阵中保持一致。

### 第四层：说话策略

一句对白首先是一项行动。写之前必须标明目的：

- 求证；
- 解释；
- 命令；
- 拒绝；
- 激怒；
- 试探；
- 套话；
- 拖延；
- 威胁；
- 讨价还价；
- 转移话题；
- 保全面子；
- 隐瞒真相；
- 争取旁观者；
- 表面答应、实际设局。

同一句信息，由不同人物完成时，应采取不同策略。

### 第五层：压力变形

情绪不会把人物变成另一个人，而会放大或破坏他的原有语言习惯。

```text
平静：完整表达
警觉：问题增多，解释减少
愤怒：句子缩短，判断绝对化
恐惧：重复、停顿、话题跳跃
悲痛：称谓变亲，动作代替语言
说谎：理由过多或过分完整
极端压力：恢复最本能的词汇与价值判断
```

## 四、十二种代表性声纹

以下不是要求复制原人物，而是提炼可迁移的人物语言机制。

### 1. 郭靖型：质朴、字面、承诺驱动

#### 稳定特征

- 句子短，主谓关系清楚；
- 不懂便问，不以无知为耻；
- 较少使用弯曲的暗示；
- 常先说明事实，再说明自己应该怎样做；
- 道德表达落在“答应过、不能失信、该不该”上；
- 长句通常用于复述经过或认真说明学到的道理。

#### 典型生成路径

```text
听不懂 → 直接询问
两种义务冲突 → 分别说出两边承诺
决定行动 → 用朴素因果说明
受到讥笑 → 先判断事情是否有理，不先保全面子
```

#### 禁忌

- 不突然说精密讥刺；
- 不轻易使用多层套话；
- 不为聪明而隐藏简单问题；
- 不长篇分析他人复杂心理。

### 2. 黄蓉型：机敏、变调、控制话语框架

#### 稳定特征

- 问句多，但问题往往已含答案或陷阱；
- 能在少女口语、江湖俏皮、礼貌谦辞和典籍语言间快速切换；
- 善用昵称、绰号和故意降格的称呼重新定义关系；
- 解释时按线索逐层推进；
- 对敌人常先表面顺从，再改写问题前提；
- 真情流露时反而会变得简单，不再炫技。

#### 典型生成路径

```text
先观察对方最在意什么
→ 选择其愿意接受的称呼和前提
→ 提出看似无害的问题
→ 让对方确认一小步
→ 推出真正结论或陷阱
```

#### 禁忌

- 不要每句都卖弄典故；
- 不要把聪明写成无所不知；
- 不要只有俏皮，没有情感软处；
- 不要让计谋脱离她实际掌握的线索。

### 3. 洪七公型：市井外壳、领袖判断

#### 稳定特征

- 喜欢自称、绰号、饮食和身体化比喻；
- 骂人常有喜剧节奏；
- 讲道理不空谈，常落到人物做过什么；
- 平时随便，遇到大是大非立即变得直接庄重；
- 长篇说明像讲江湖旧事，一面叙事一面评论。

#### 核心反差

```text
表层：馋、懒、爱玩笑
深层：见识广、识人准、公共责任明确
```

### 4. 黄药师型：孤傲、压缩、反问裁断

#### 稳定特征

- 少解释自己的情绪；
- 常用反问把对方置于被审位置；
- 判断语气强，带讥诮；
- 对同辈高手可切换为有分寸的旧式客套；
- 涉及女儿或亡妻时，语言出现停顿、转题和失控。

#### 禁忌

- 不喋喋不休证明自己厉害；
- 不向普通敌人详细解释计划；
- 不在公开场合轻易直接说柔情。

### 5. 周伯通型：儿童逻辑、递归讲述

#### 稳定特征

- 对白最长，容易岔开；
- 自问自答、反复追问；
- 把危险、比武、输赢都转成游戏；
- 爱用第三人称或绰号称自己；
- 讲故事时不断插入评价、旁枝和模仿他人说话；
- 真正的严肃性常从“师哥”及旧事中泄露出来。

#### 写作控制

长并不等于无结构。内部通常仍是：

```text
先说结论
→ 想起一件旧事
→ 模仿当时对白
→ 插入一个滑稽旁枝
→ 回来追问听者
```

### 6. 欧阳锋型：条件、筹码、后果

#### 稳定特征

- 表面克制，少说无收益的话；
- 擅长把威胁说成客观后果；
- 常用对称条件：“我若如何，你便如何”；
- 对同级高手保留礼貌，对弱者迅速转为命令；
- 询问多用于确认信息和谈判，不为闲聊；
- 被揭穿时先评估证据，不急于情绪辩白。

#### 典型路径

```text
确认对方想要什么
→ 指出其缺少什么
→ 将自己掌握的东西变成筹码
→ 提出看似公平的交换
→ 隐藏真正风险
```

### 7. 杨康型：身份适配、合理化、自我保护

#### 稳定特征

- 面对不同阵营迅速改变自称和称谓；
- 善于说出对方希望听见的版本；
- 很少直接承认核心动机，常以局势、亲情或不得已包装；
- 辩解结构通常完整、可信，且掺有部分真话；
- 危急时会把选择说成“唯一办法”。

#### 关键原则

这种人物不能总说明显假话。最有效的是：

```text
真实事实
＋选择性省略
＋动机改写
＝有说服力的自我辩护
```

### 8. 柯镇恶型：集体荣辱、道德裁决

#### 稳定特征

- “我”常转成“我们、咱们兄弟”；
- 说话以侠义名声、是否怕死、是否受辱为尺度；
- 不爱模糊推测，一旦判断便迅速裁决；
- 命令和反问较多；
- 即使承认技不如人，也要维护道德尊严。

#### 风险

优点与缺点来自同一语言机制：判断果决，所以容易被错误证据带入刚愎。

### 9. 丘处机型：身份礼语、责任叙事

#### 稳定特征

- 以“贫道”等自称稳定身份；
- 对江湖同道保持正式称呼；
- 解释事情时常交代因果、约定和自己应负的责任；
- 能公开认错，但认错仍带英雄式决断；
- 愤怒时古雅礼语减少，命令和斥责增多。

### 10. 梅超风型：师门、债与逼问

#### 稳定特征

- 短句和问句密集；
- 语言围绕报仇、胜败、师门威名和旧债；
- 对敌人强硬，对师父极度自卑恭顺；
- 情感越深，越难直接说柔软的话。

### 11. 穆念慈型：见证叙述、迟疑与断裂

#### 稳定特征

- 讲经过时细而完整；
- 谈到感情和背叛时出现重复、省略和未完句；
- 道德问题常以质问爱人表达；
- 较少玩弄语言，重在“我亲眼听到什么”。

### 12. 一灯型：缓慢因果、自我审判

#### 稳定特征

- 长篇自述以时间和因果推进；
- 少替自己开脱，反而主动加重责任；
- 使用平静语气讲极痛之事；
- 常有叹息、停顿和自我校正；
- 权威来自承担，而不是不断命令别人。

## 五、称谓是关系动作

称谓不能只看身份表，还要看人物当下要对关系做什么。

同一个称谓可能承担：

- 真正亲近；
- 请求照顾；
- 故意抬高；
- 表面恭敬；
- 拉入同一阵营；
- 拉开距离；
- 讥刺；
- 激怒；
- 恢复旧关系。

写作时应记录称谓变化：

```yaml
speaker:
target:
neutral_address:
intimate_address:
formal_address:
hostile_address:
manipulative_address:
stress_reversion:
```

真正重要的往往不是人物使用哪个称谓，而是他什么时候突然换了称谓。

## 七、对白生成流程

### 步骤1：确定人物此刻首先注意什么

不要先想台词。先写一句内部说明：

> 他此刻最在意的是______。

### 步骤2：确定知识权限

- 他亲眼知道什么？
- 他只听说过什么？
- 他误以为什么？
- 哪些信息他绝不可能知道？

### 步骤3：确定真实目的

> 这句话表面在______，实际想让对方______。

### 步骤4：确定关系语域

选择称谓、自称、礼貌程度和是否解释理由。

### 步骤5：套用人物句法

确定：

- 句长；
- 问句比例；
- 是否会自我修正；
- 是否会使用典故；
- 是否完整说出感情；
- 是否使用动作代替后半句。

### 步骤6：施加情绪变形

让压力改变原有声纹，而不是换成统一的“愤怒文学”。

### 步骤7：检查对白后果

一句有效对白至少改变一项：

- 信息；
- 权力；
- 关系；
- 行动；
- 风险；
- 旁观者判断。

## 八、可直接交给AI的人物声口指令

```text
为每个主要人物维护独立的语言系统，不用统一的作者口吻代替人物说话。

生成每句对白前，依次确定：
1. 人物此刻最关注的事实；
2. 人物实际知道、误以为和不知道的内容；
3. 这句话的表面功能与隐藏目的；
4. 说话人与听者的关系、地位和公开/私下场合；
5. 人物惯用的句长、称谓、问句方式、礼貌程度和知识语域；
6. 当前情绪如何放大或破坏其正常句法。

人物声口应由稳定规则生成，而不是反复使用口头禅。每个场景只使用一两个轻微声纹标记，优先通过注意力、推理方式和说话策略体现差异。

不允许人物说出其知识边界之外的信息；不允许所有人物都能完整分析自己的情绪；不允许聪明人物每句话都引用典故；不允许粗豪人物永远只会骂人。

对白必须是行动：试探、说服、拖延、激怒、拒绝、隐瞒、交换、求助或裁决。若删去一句对白，对信息、关系和行动均无影响，应考虑删除。
```

## 十一、七项测试

### 1. 去名辨人测试

删掉说话标签后，关键对白是否仍能从注意力、逻辑和关系语域判断说话人？并非每句都必须做到，但关键句应有辨识度。

### 2. 对调测试

把甲的台词交给乙。如果基本无需修改，说明人物声口尚未建立。

### 3. 知识泄漏测试

人物是否说出了自己不可能知道的历史、动机或线索？

### 4. 关系一致性测试

称谓、礼貌和解释程度是否符合双方当前关系？关系变化后语言是否随之变化？

### 5. 压力变形测试

愤怒和悲痛是否只是统一增加感叹号，还是人物原有语言习惯发生了独特变形？

### 6. 策略结果测试

对白是否完成试探、说服、拖延、威胁或隐瞒，而不仅传递背景资料？

### 7. 口头禅密度测试

删除人物最明显的绰号、口头禅后，声口是否仍然成立？若不成立，说明写法停留在表面。

## 十二、常见失败

- 用口头禅代替人物思维方式；
- 所有人都能引经据典；
- 所有人都准确理解自己的感情；
- 所有人愤怒时都变成短句和感叹号；
- 聪明人物永远正确，没有知识盲区；
- 老实人物只会说傻话，没有成长后的复杂表达；
- 反派说话总带明显恶意，无法欺骗任何人；
- 对任何对象都使用相同称谓和礼貌；
- 对白只负责交代作者想告诉读者的资料；
- 每句话都追求强烈辨识度，反而形成漫画化表演。

## 十三、后续reference方向

- 各人物常用称谓与关系变化表；
- 同一人物对师长、爱人、敌人和陌生人的变调案例；
- 请求、拒绝、威胁、试探、套话、认错的多人物对比语料；
- 平静、愤怒、恐惧、羞愧、悲痛状态下的句法变化；
- 直接对白、心理语言和转述语言的声口一致性；
- 人物知识边界与错误知识清单；
- 可替换的原创人物声口原型库。
