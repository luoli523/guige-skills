# 金庸写作风格卡·十二类句式与语块模板

本模块由 `SKILL.md` 按任务类型加载。

## 一、总原则

句子通常不是由一个漫长结构拖到底，而是由若干意义自足、节奏清楚的短语块连接而成。

```text
实体或方位
→ 状态或动作
→ 局部变化
→ 人物判断
→ 结果或落点
```

语块多为四至八字，但这不是硬性字数。真正重要的是每一块只承担一个清楚功能。

## 三、十二类句式

### 1. 景物句

#### 功能

- 建立地域、时令和方向；
- 给人物行动设置空间；
- 用环境状态承载气氛；
- 为突发事件提供稳定基线。

#### 基本结构

```text
地点或水陆总貌
→ 时令天气
→ 主体景物
→ 局部颜色、声音或运动
→ 气氛或人物感受
```

#### AI模板

```text
【地域】A横贯／环绕B，【时间】正是C时节。
【主体】近处D，【细节】颜色／形态E；
【动态】远处F渐渐G，【余味】更显H。
```

#### 使用规则

- 先定空间，再给修辞；
- 景物必须包含一个运动或变化；
- 情绪尽量放在景物之后，不先宣布气氛；
- 新场景可写全，连续动作只补必要方位。

### 2. 人物登场句

#### 功能

- 将新人从画外引入；
- 暂时隐藏身份；
- 通过旁观者反应抬高分量。

#### 基本结构

```text
先有声音或动作
→ 只见一人
→ 类别、年龄或身形
→ 两三个识别特征
→ 正是／却是身份
→ 在场人物反应
```

#### AI模板

```text
忽听A，只见B处走来一人，约莫C，身形D，手中E。
那人F，众人见了G；原来／正是H。
```

#### 使用规则

- 重要人物先写效果，后报姓名；
- 首次登场选两至四个签名特征；
- 再次登场只需一个识别物或动作；
- 不把履历一次性塞进外貌段。

### 3. 人物外貌句

#### 功能

- 建立视觉记忆；
- 暗示身份、性格、生活方式；
- 制造外貌与能力的反差。

#### 基本结构

```text
年龄与体格
→ 面部最显著之处
→ 服饰或随身物
→ 姿态与动作
→ 整体印象
```

#### AI模板

```text
此人年约A，身材B；一张C的脸，最显眼的是D。
身穿E，手持F，站在那里G，看来H。
```

#### 使用规则

- 不平均描写五官；
- 优先选择能在后文复现的特征；
- 外貌最好包含姿态，而非静态肖像；
- “看似A，实则B”的反差可用于藏拙和误导。

### 4. 神态与身体反应句

#### 功能

- 把抽象情绪落到身体；
- 表现伤势、内力、恐惧和克制；
- 作为心理与行动的接口。

#### 基本结构

```text
外部刺激
→ 一凛／一怔／一震
→ 面色、呼吸、四肢变化
→ 情绪辨认
→ 下一动作
```

#### AI模板

```text
人物听到／见到A，心中一B，脸上C，呼吸D；
强自E片刻，终于F。
```

#### 使用规则

- 情绪、伤势和内力应有不同身体表现；
- 可用“渐渐、愈来愈、到后来”写递进；
- 强烈情感常先压制，再释放；
- 不在身体反应后重复解释“他非常害怕”。

### 5. 心理判断句

#### 功能

- 解释人物怎样理解线索；
- 展示知识边界和性格偏见；
- 形成计划或误判。

#### 基本结构

```text
眼前事实
→ 心想／寻思
→ 调取旧信息
→ 分析条件
→ 得出结论
→ 当下行动
```

#### AI模板

```text
人物见A，心想：“B既然C，多半D；若是E，只须F。”
当下G。
```

#### 使用规则

- 心理是一段小型论证，不是抽象抒情；
- 聪明人物多出现“转念”和条件分支；
- 错误判断也应建立在真实证据上；
- 心理结束后必须影响动作或说话策略。

### 6. 日常动作句

#### 功能

- 维持身体与空间连续；
- 用物件交换表达关系；
- 在非高潮处证明人物感情与身份。

#### 基本结构

```text
拿起物件
→ 具体处理动作
→ 方位或递交对象
→ 对方接收或拒绝
→ 关系结果
```

#### AI模板

```text
人物伸手A，将B轻轻C，又向D处E；
另一人F，却没有G。
```

#### 使用规则

- 一块只写一个主要动作；
- 使用准确动词与方向补语；
- 不用“做了一系列动作”代替过程；
- 递物、扶持、包扎、让座常比直接表白更有效。

### 7. 武打句

#### 功能

- 保持攻防关系和空间清楚；
- 用结果证明速度、力量和招式性质；
- 让战斗改变局势。

#### 基本结构

```text
攻击者与目标
→ 方向、身体部位、兵器
→ 对方格挡或闪避
→ 接触
→ 身体或物件结果
→ 局势变化
```

#### 动词组

- 发动：抢、探、挥、劈、刺、扫、撩、削、点；
- 防御：挡、格、架、卸、引、带、封、闪、避、退；
- 结果：中、麻、痛、脱、飞、倒、断、折、震、跌。

#### AI模板

```text
甲A手／兵器B，直取乙C；
乙D，正待E，哪知F已G；
只听H一声，乙I，局面J。
```

#### 使用规则

- 每一招必须写清谁对谁；
- “正待—哪知—已”可以制造速度；
- 招式名只在转折和识别处出现；
- 先写奇怪结果，再补武理解释；
- 一轮攻防后必须改变距离、伤势、兵器或目标。

### 8. 对白与说话标签

#### 功能

- 让人物实施试探、命令、欺骗、拖延和结盟；
- 通过称谓与语气表现关系；
- 打断叙述节奏。

#### 基本结构

```text
动作或神态
→ 简洁说话标签
→ 台词
→ 听者反应或行动
```

#### AI模板

```text
人物A了一下，道：“B。”
另一人C，没有立即回答，隔了片刻才道：“D。”
```

#### 使用规则

- 以“道”为默认标签；
- 只有声音和态度增加新信息时才修饰标签；
- 允许重复、停顿、中断和未完句；
- 称谓承担关系变化；
- 对白必须改变信息、权力、关系或行动。

### 9. 镜头引导句

#### 功能

- 控制读者先看什么、后看什么；
- 延迟身份与机关揭示；
- 区分视觉事实与人物推断。

#### 基本结构

```text
方向与观察位置
→ 只见／但见
→ 整体轮廓
→ 局部细节
→ 正是／却是
→ 人物反应
```

#### 信号分工

- 只见：首次揭示具体对象；
- 眼见：正在迫近的局势；
- 但见：较宽广或强调性的场面；
- 却见：与预期不同；
- 忽见：突然进入视野。

#### 使用规则

- 用距离、光线和遮挡限制信息；
- 线索可先以部分物件出现；
- 不在同一瞬间展示所有细节；
- 先写事实，再写人物如何解释。

### 10. 突发触发句

#### 功能

- 打断稳定状态；
- 从画外引入新事件；
- 取消人物原计划；
- 加速危机。

#### 基本结构

```text
正在进行的动作
→ 忽听／忽见／突觉
→ 感官碎片
→ 身体反应
→ 识别或后果
```

#### 信号分工

- 忽听：画外危险，悬念最强；
- 忽见：事物突然进入画面；
- 忽觉、突觉：身体先于意识；
- 猛然、蓦地：强烈意识或身体转折；
- 哪知、岂知：人物预期落空；
- 不料：事件层面的结果翻转。

#### AI模板

```text
人物正要A，忽听／忽见B，心中C，忙D；
哪知E，已然F。
```

### 11. 因果揭示句

#### 功能

- 解释异常结果；
- 补充武理、机关和背景；
- 校正人物认识；
- 形成小型恍然。

#### 基本结构

```text
先出现现象或结果
→ 原来A
→ 只因B，兼之C
→ 是以D
→ 人物这才明白
```

#### 信号分工

- 原来：先果后因，揭开机关；
- 只因、兼之、是以：组成原因链；
- 要知、须知：叙述者补充必要常识；
- 这才、才知、方知：标记迟到的理解；
- 其实：校正表面认识或自我认识。

#### 使用规则

- 先让解释成为需要；
- 每个原因尽量具体；
- 区分作者揭底与人物推断；
- 解释完成后迅速返回行动。

### 12. 段落收束句

#### 功能

- 将变化后的状态定格；
- 留下情绪余味；
- 结束一个节拍或打开下一场。

#### 两种模式

```text
闭合式：动作完成／人物离场／声音消失／恢复宁静
开口式：新声响／新人出现／危险动作将发／一句“且慢”
```

#### 常见落点

- 身体结果：晕倒、无言、无法可施；
- 距离消失：声音渐远、没入黑暗；
- 静默定格：默然不语、悄立良久；
- 情绪余味：心事重重、郁郁而回；
- 决心威胁：当下起行、便要动手；
- 反讽小扣：末句重释前文；
- 新钩子：忽听脚步、忽来军马。

#### AI模板

```text
【渐远】A渐行渐远，B越来越低，终于C；人物D良久，才E。
【静止】众人A，半晌B，但听得C。
【余味】人物见A，不由得B，一时C，一时D，E不已。
【钩子】人物正要A，忽听B；只见C。
【反讽】众人A，却忘了／其实B。
```

## 四、十二类的组合方式

一个完整场景通常不是连续使用同一种句式，而是：

```text
景物或镜头引导
→ 人物登场
→ 对白
→ 心理判断
→ 日常动作或武打
→ 身体反应
→ 因果揭示
→ 收束或新触发
```

场景紧张时可缩短景物和外貌；关系场景可增加日常动作、对白和停顿；谜案场景应强化镜头、心理误判和因果揭示。

## 五、AI调用规则

```text
写每一段前，先判断它属于哪一种主要句式功能；一段可以组合两至三类，但必须有主次。

先列出语块功能，再写完整句子：
【主体】【动作】【方向】【局部变化】【判断】【结果】。

每个语块只承担一个主要信息。四至八字是常见节奏，不是必须凑足的格式。

不得连续机械套用同一模板；模板用于保证空间、因果和节奏清楚，具体词汇必须服从人物、场景和时代。
```

## 六、检查清单

- 这一段主要承担哪类功能？
- 每个语块是否只表达一个清楚动作或状态？
- 主体、方向和结果是否明确？
- 视觉事实与人物判断是否分开？
- 心理是否影响行动？
- 武打是否改变局势？
- 对白是否完成行动目的？
- 解释是否出现在疑问形成之后？
- 收束是要闭合还是打开？
- 是否为了模仿而堆积四字词和连接词？
