# 金庸写作风格卡·文化织入法

> 本文只记录“文化材料怎样进入故事”的写法机制。具体诗词、史料、典故、传说、礼俗、地域风物等素材，后续分别建立 reference 库，不与规则层混写。

本模块由 `SKILL.md` 按任务类型加载；素材的数据结构见 `reference-library.md`。

## 一、核心原则

典故、传说、习俗和风土人情不应只是古雅装饰，而应进入人物语言、社会规则、行动能力、情节机关和主题结构。

文化材料由浅入深可分五层：

1. **背景纹理**：提供时代与地域质感。
2. **社会规则**：决定人物怎样待客、结义、婚配、服丧、拜师和处理冲突。
3. **人物能力**：表现人物的出身、教养、知识边界与思维方式。
4. **情节机关**：帮助过关、破阵、寻物、识人、定约、误判或揭谜。
5. **主题骨架**：将公共历史、文化记忆转化为人物一生反复面对的道德问题。

使用原则：文化材料至少承担两项功能；只提供知识展示、不能改变人物或场面的内容应慎用。

## 二、主要织入方法

### 1. 历史种子化

```text
公共历史或集体创伤
→ 人物姓名、家训、遗物或誓言
→ 中段反复提醒
→ 后段转化为现实选择
→ 完成命运与主题回收
```

作用：历史不再是背景说明，而成为人物无法摆脱的身份和道德命题。

### 2. 历史情节化

将真实人物、事件、诗文或遗物转化为争夺目标、谜面、线索、行动理由或阵营冲突。

```text
历史材料
→ 当代人物欲望
→ 寻找、保护、解释或争夺
→ 阵营行动
→ 家国主题进入私人命运
```

### 3. 典故动作化

典故不只用于命名，还要转化为动作机制。

```text
原典意象
→ 原典哲理
→ 身体动作或运行原则
→ 实际效果
→ 人物成长或性格映照
```

检查标准：名称、动作、效果和精神含义应彼此相通。

### 4. 知识交锋化

让诗文、经书、谜语、联语和历史知识成为人物之间的攻防工具。

```text
双方共享一个文化文本
→ 各自作出不同解释
→ 正解、曲解、反用或戏拟
→ 性格与知识边界暴露
→ 胜负、关系或通行权改变
```

重点不在展示作者知道答案，而在人物如何使用知识达到眼前目的。

### 5. 诗意跨域化

将诗词意象映射到饮食、武功、器物、机关、建筑或场景。

```text
诗句意象
＋形状、颜色、声音或数量对应
＋制作或运行技法
＋人物专长
＝具有文化意味且能实际运作的事物
```

避免只给普通事物贴一个华丽名称。

### 6. 风俗剧情化

```text
陌生规矩出现
→ 人物遵守或无意触犯
→ 本地人物产生强烈反应
→ 关系、名誉、婚约或冲突改变
```

风俗应通过行为后果被读者理解，不宜先写成长篇百科说明。

### 7. 地域具身化

```text
地貌与气候
→ 交通和生产方式
→ 食物、服饰、器物
→ 礼俗与称谓
→ 人物身体技能
→ 当地特有的情节形态
```

地域感不能只有地名和景物形容。真正的地域感是“当地人知道怎样行动，外来人却可能不懂”。

### 8. 节令时钟化

将节日、节气、月相、庙会或祭礼设为约期和叙事倒计时。

```text
建立节令之约
→ 在旅程和对白中反复提醒
→ 用天气、月相、农事暗示逼近
→ 在节令场景集中人物和矛盾
```

### 9. 礼俗契约化

结义、婚约、拜师、敬酒、服丧、祭拜等仪式应建立真实约束，后文违背或坚守时才有重量。

```text
仪式行为
→ 关系获得公开名称
→ 形成权利与义务
→ 新利益出现
→ 人物被迫选择守约或背约
```

### 10. 传说处境化

不必完整复述一则传说。只取其中与人物当下处境相似的关系、意象或命运结构，用一句话点到即可。

### 11. 民间声音人物化

神鬼信仰、吉凶禁忌、俗语谚语应属于具体人物和社会阶层：

- 市井人物可在惊慌时混合祈求多路神明；
- 江湖人物可用俗语解释经验；
- 读书人重经传、对仗和名分；
- 边地人物使用本地称谓、礼制和战争语言。

文化知识的分布，本身就是人物塑造。

### 12. 文化回收

```text
首次出现：一句轻释
→ 日常复现：自然进入称谓和行为
→ 情感积累：与人物关系绑定
→ 关键回收：成为道德冲突或命运重词
```

## 三、叙述层的使用方法

### 首次解释

- 生僻词第一次出现时只解释最低必要信息。
- 优先采用“行为在前、意义在后”。
- 解释后立即回到人物反应或事件结果。

### 后续复现

- 不重复百科说明。
- 让词语自然出现在称呼、对白、礼仪和行动中。
- 每次复现可增加一层关系或情感意义。

### 高雅与通俗调和

- 经书可以被曲解、反用和戏拟。
- 古典联语可以承担讥刺和幽默。
- 诗意可以进入饮食与日常生活。
- 俗语可以承担判断和推理。

高雅材料不能一直保持供奉状态；人物要能够实际使用它。

## 四、人物文化边界卡

为每个主要人物单独记录：

```yaml
character:
  education_source: 家学、师承、寺观、军旅、市井、部落
  knows:
    - 熟悉的典籍、传说、礼法和地方规则
  partially_knows:
    - 会引用但未必真正理解的内容
  does_not_know:
    - 面对某种文化时的盲区
  usage_style:
    - 正解、曲解、卖弄、避讳、俗解、实用化
  speech_register:
    - 古雅、质朴、市井、宗教、军旅、边地
  plot_function:
    - 其知识如何帮助或妨碍行动
```

所有人物不应拥有同样的文化水平和同一种作者口吻。

## 五、真实性分层

```text
硬锚层：真实人物、地点、年代、文本、制度
连接层：可信的日常习惯、器物、称谓、交通与社会关系
虚构层：人物、秘笈、阴谋、巧合与传奇事件
```

素材进入 reference 库时，需要标明：

- `fact`：有可靠史料支持；
- `contested`：来源互异或存在争议；
- `legend`：地方传说或民间叙事；
- `literary`：前代文学作品中的表达；
- `adapted`：为故事进行的艺术加工；
- `invented`：纯虚构材料。

## 七、写作检查清单

- 这条材料属于哪个人物，而不是只属于作者吗？
- 它是否改变了行动、关系、判断或情节？
- 初次解释是否短而清楚？
- 是否能通过动作和后果展示，而非百科介绍？
- 是否与地域、时代和人物身份相符？
- 是否区分了史实、争议、传说和虚构？
- 后文是否有自然复现或更深回收？
- 如果删掉它，故事是否毫无变化？若是，考虑删除或重新嵌入。

## 八、应避免的“伪文化感”

- 连续引用诗文，却不改变情节。
- 所有人都同样博学、说同一种古雅语言。
- 地方风情只有地名、服装和菜名标签。
- 先写一段百科，再继续故事。
- 招式或物件的典故名称与实际机制无关。
- 为显示古代感而堆积生僻名词。
- 把地方传说或小说虚构误写成确定史实。
- 只在首次出现时展示材料，后文不再使用和回收。
