# 命名与语义网络

本模块研究人物名、别号、群体称号、门派、武学、器物、地名和章回题目怎样共享文化词源与动作逻辑，形成既可辨认又能持续变义的语义网络。文化材料的剧情化见 `culture-weaving.md`，人物怎样使用称谓见 `character-voice.md`，器物名称与状态历史见 `object-lifecycle.md`。

## 一、核心结论

好名称不是孤立地“取得好听”，而是在一张网络中同时回答：

```text
谁命名
＋依据什么文化与生活经验
＋命给哪类事物
＋名称对应什么可见特征或运行原理
＋哪些同类名称共享规则
＋谁知道、接受、嘲弄或拒绝这个名字
＝名称的叙事效力
```

名称至少承担一种现实功能：

- 帮读者迅速区分人物与阵营；
- 暗示出身、地域、职业、师承或时代；
- 压缩外貌、能力、性格或社会评价；
- 使同一门武学或同一群体形成家族相似；
- 让历史、典故和价值进入人物命运；
- 保存旧身份，并在后文被重新解释；
- 成为认证、试探、羞辱、亲近或夺权的语言动作。

若名称只负责“显得古雅”，换成另一个华丽词后剧情与人物毫无变化，它就是装饰。

## 二、全书观察

### 1. 人物本名可成为历史种子

开篇一对尚未出生的孩子，由有明确政治立场和文化知识的人命名。两个单字并排才组成一段公共历史记忆，名字又被刻在成对信物上。于是姓名同时进入：

```text
父辈记忆
→ 身份证明
→ 养育期待
→ 人物实际选择
→ 名义与人生是否相符的审判
```

名字不是预言，而是一项长期交付给人物的价值问题。

### 2. 同门名字建立代际可见性

桃花岛弟子的名字共享“风”字，但前一字仍各有辨识度。读者即使暂时记不清人物，也能感到他们属于同一代际。全真门人的道号则共享道教语汇与“子、散人”等身份格式，和俗家姓名形成双层身份。

这类规则的作用不是整齐，而是让师承在名字里可见。

### 3. 绰号是公共评价的压缩

江南七怪的别号分别取自身体特征、职业伪装、专长、兵器、活动空间和人物气质。名称先提供清楚轮廓，后续行动再证明、补充或反讽它。黑风双煞、铜尸铁尸等称呼则把气候、材质、身体和恐惧压缩为不同层级的公共传闻。

同一个人可以同时拥有：

```text
本名
＋师门名
＋江湖绰号
＋敌人口中的骂称
＋亲近者的私称
```

这些名称不是同义词，而是不同关系对人物的解释权。

### 4. 群体称号可以构成网格

东、西、南、北、中与邪、毒、帝、丐、神通形成一个高度可记忆的五点系统。方位提供空间秩序，后半部同时标记行事风格、社会身份或能力评价。各项结构相同，内容却不雷同。

这说明群体命名最有力的形式是：

```text
统一槽位
＋成员各自不同的高信息词
```

### 5. 武学名称来自门派自己的世界观

- 丐帮的棒法名称直白、实用，核心诀窍甚至压缩为单字动作；
- 降龙掌的招名来自经典文本，并与蓄力、进退、位置和刚柔原则对应；
- 桃花岛的掌、指、剑与乐曲共享花木、落英、碧海、玉箫等审美领域；
- 全真阵法把星位、人数、方位和协作机制合成一个名称；
- 西域毒术常借蛇虫身体和蓄势方式命名；
- 被误读的阴性经文衍生出白骨、摧心等恐怖名称，也显出练习者怎样理解原典。

招式名不是贴纸，而是门派认识身体、自然和力量的方式。

### 6. 名称可以被改俗、误读与反用

某些经典招名因太过文雅拗口，被使用者改成更顺口、更具画面的说法；粗俗的棒法名称却配以极精妙的技术。名字的雅俗和能力高低并不必然一致。

这种反差使名称具有生活感：它们经过真人使用，而非都由同一位作者在书斋里整齐命名。

### 7. 章回题目是记忆索引

四十回题目绝大多数采用四字结构，但内部功能不断轮换：

- 天候与巨变；
- 地域与群体；
- 核心人物或身份；
- 招式、经书与器物；
- 具体行动；
- 空间困局；
- 关系新旧；
- 道德判断；
- 大规模历史行动。

题目不复述整章摘要，而是选取最能在读后召回这一章的图像、动作、专名或命题。

## 三、名称的六层结构

### 1. 指称层

它首先必须让人知道在说谁、哪一招、哪一处。专名过于相似，会破坏最基础的导航功能。

### 2. 感官层

声音是否顺口，字形是否易辨，读者能否第一次听见就留下粗略轮廓。

### 3. 社会层

名称透露谁有资格这样叫：父母取名、师父赐名、同道起号、敌人蔑称、百姓俗称、官府定名。

### 4. 文化层

名称从哪套词库取材：经史、宗教、地域、职业、物候、军旅、民间口语或外语音译。

### 5. 机制层

武学、器物和阵法名称是否对应实际结构、动作、材料、方位或使用限制。

### 6. 叙事层

名称在首次出现、中段误读和最终选择中是否变义。一个好名字往往先帮助识别，后来才承担主题。

## 四、语义网络模型

不要维护孤立名字清单，而要维护“节点—关系”。

### 1. 节点类型

```text
人物｜家族｜师门｜组织｜地域｜武学｜招式
器物｜典籍｜地点｜事件｜章回题目｜称谓
```

### 2. 常用关系

| 关系 | 例义 |
|---|---|
| 同源 | 来自同一经典、地域或生活领域 |
| 同代 | 共享字辈、后缀或格式 |
| 对举 | 东西、阴阳、动静、新旧 |
| 从属 | 招式属于武学，人物属于师门 |
| 继承 | 名称由前代传下或被后人改写 |
| 反讽 | 名称与人物现实表现出现张力 |
| 认证 | 只有知情者能凭名称识别身份 |
| 蔑称／尊称 | 名称改变关系和权力位置 |
| 变义 | 同一名称在不同阶段获得新含义 |
| 回声 | 章名、地名、器物名与主题互相召回 |

### 3. 语义家族

一个阵营可选择二至四个核心意象，再分配给不同类别：

```text
核心经验：潮汐、礁石、海雾
门派空间：听潮坞
身法系统：逐汐步
内功层级：伏潮、回澜、平海
器物：雾灯
人物常用比喻：水路、风向、暗礁
```

家族相似不等于每个名称都含“潮”字。可以共享运动规律、材质和声音，而不是机械复字。

### 4. 对立网络

敌对阵营不必只靠“黑与白”区分。可在同一主题上作不同解释：

```text
山门甲：把水理解为顺势、容纳、回旋
山门乙：把水理解为侵蚀、淹没、无孔不入
```

共享词源能显示历史关联，解释分歧才能制造思想冲突。

### 5. 跨类别回声

最有效的语义网络通常跨越三类以上节点：

```text
人物名字中的“归”
→ 师门戒语“知止而归”
→ 失落故城名“归浦”
→ 终章题目“无舟可归”
```

回声应来自故事中的真实关系，不要为了押主题硬凑同字。

## 五、命名者与命名权

### 1. 先问“谁取的”

名称的文化水平不能高于命名者。乡民会按地形、事故和用途取名；官府偏制度与吉祥；文士可能用典；匠人重材料和工序；江湖传闻重可见特征；本人自号常暴露理想形象。

### 2. 自称与他称分开

```text
组织自称：体现宗旨与合法性
百姓俗称：体现日常经验
敌对蔑称：体现冲突框架
史家后称：体现后来的评价
```

若所有人都使用组织最希望别人使用的正式名称，世界会失去社会摩擦。

### 3. 命名也是权力

- 师父赐名，确认师承并改变旧身份；
- 皇帝赐号，纳入政治秩序；
- 江湖起号，公共评价可能压过本名；
- 敌人只叫旧名，拒绝承认新身份；
- 亲近者恢复乳名，缩短距离；
- 当众直呼尊者本名，可以挑衅、认证或揭密。

### 4. 名称接受度

人物可能：

- 主动拥抱绰号；
- 表面厌恶、实际享受；
- 只允许特定人使用；
- 因旧事拒绝本名；
- 用自嘲抢先化解羞辱；
- 在获得新身份后仍沿用旧名。

把这种态度写入人物卡，名称才会进入对白行动。

## 六、人物本名、字辈与改名

### 1. 本名的四种来源

| 来源 | 主要作用 | 风险 |
|---|---|---|
| 家族愿望 | 品德、平安、功名、延续 | 人人名字都像训诫 |
| 历史记忆 | 纪念事件、故国、旧耻 | 解释过重，像作者命题 |
| 地域生活 | 物候、生产、出生地点 | 只把景物字随意拼接 |
| 偶然现场 | 梦、异象、救命物、时辰 | 过度宿命化 |

### 2. 名字不等于性格标签

“勇”不保证勇敢，“静”也不要求人物安静。名字是命名者的期待，人物如何回应期待才是故事。

### 3. 字辈规则

使用共享字时，保留第二重差异：

```text
共享项：同一代弟子都含“舟”
差异项：前字分别来自材质、方向或性格期待
声音项：避免五人都同声母同韵母
```

字辈能帮助识别亲属和师承，也可能泄露秘密身份。若剧情需要隐藏，决定人物是否改名、避用或被知情者识破。

### 4. 双名系统

古代或宗教语境可存在：

```text
本名｜字｜乳名｜法名／道号｜官称｜江湖号｜化名
```

不要一次全部介绍。根据场景关系逐层开放。

### 5. 改名的叙事条件

改名应对应身份变化：拜师、出家、叛门、赦免、复国、逃亡、认祖、拒绝旧命。至少有一位命名者、一项公开后果和一个不肯采用新名的人。

### 6. 外族与跨语际人物

- 优先尊重其语言与历史命名习惯；
- 音译名不强行附会汉字寓意；
- 同一人可能有本族名、汉名、官号和汉人误称；
- 保持译写一致，避免为“好听”频繁换字；
- 相似长名可用身份、亲属关系和稳定短称帮助读者区分。

## 七、绰号、尊号与群体称号

### 1. 绰号的七种来源

```text
外貌｜兵器｜绝技｜职业｜地域｜著名事件｜性格与行事
```

优秀绰号通常取其中一项主来源，再用另一项制造反差。

### 2. 先有事，后有号

公共绰号最好能追溯到一次或多次可传播事件。人物第一次登场可以已经有号，但作者后台必须知道江湖为何这样叫。

### 3. 绰号不是人物简介

不要试图在六个字里同时塞入外貌、兵器、地域、性格和道德评价。轮廓越清楚，越容易记。

### 4. 尊号与蔑称的方向

同一称呼由谁说，意义不同：

- 同行用尊号：承认地位；
- 晚辈直呼绰号：可能失礼；
- 本人自称尊号：可能自负或正式；
- 敌人改一字：降低权威；
- 亲友不用绰号：拒绝公共面具。

### 5. 群体称号公式

```text
共同槽位：地域／方位／数量／身份／共同事件
＋成员差异槽位：能力／气质／社会位置
＋可口头流传的节奏
```

群体名必须与实际人数和成员变化保持连续。若成员死亡后仍沿用旧数目，应让人物或群体明确这是纪念、制度惯例或传闻滞后。

### 6. 网格型称号

适合少数顶级人物或明确席位。先定义轴：

```text
空间轴：东南西北中
自然轴：金木水火土
制度轴：五司、六席、七宿
价值轴：守、破、隐、游
```

每个槽位要有故事依据，不能为了补齐表格临时制造一位人物。

### 7. 绰号可被行动反证

“不败”者第一次失败、“独行”者开始保护同伴、“铁算盘”做出不计得失的选择，都会让旧号变义。反讽应来自人物变化，不是作者嘲弄。

## 八、门派与组织命名

### 1. 五种命名来源

- 地点：山、湖、城、寺、岛；
- 创始人或家族；
- 职业、生活方式或社会身份；
- 核心教义、誓言或修炼目标；
- 代表器物、图腾或历史事件。

### 2. 名称应影响组织生活

若门派名来自“渡口”，其成员应真正理解水路、接应、关卡或来往人群；若来自一种教义，这种教义应进入门规、争论和惩罚。

### 3. 正式名与俗称

```text
正式名：用于文书、仪式和自我合法化
短称：同行交流
俗称：百姓按所见命名
蔑称：敌人重写其形象
旧称：保留组织前史
```

### 4. 分支命名

分支可共享词根，但最好说明分裂依据：地理迁移、教义分歧、师承代际或政治选择。不要只在总派名前机械加颜色。

### 5. 组织语义不能包办个人

桃花意象属于门派，不代表每位弟子都必须穿花衣、使用花招、用花作比喻。组织提供语言环境，个人仍有职业、性格和经历差异。

## 九、武学命名系统

### 1. 从机制反推名称

先写无专名版本：

```text
身体部位：掌、指、腿、步、息
运动路径：直进、回旋、借力、缠绕、蓄势
力量特征：刚、柔、迟、疾、震、引
使用场景：水上、狭地、群战、护人
思想来源：经典、职业、动物、天象、工艺
```

名称应至少映射其中两项。

### 2. 总名与招名分层

```text
武学总名：提供核心意象与技术承诺
招式名：标记局部位置、动作或变化
口诀字：用于临战选择和教学
俗称：外行按效果所起
```

不是每个动作都需要招名。只给关键分支、教学地标和回收动作命名。

### 3. 四类武学词源

| 词源 | 适合机制 | 注意 |
|---|---|---|
| 经典文本 | 哲理、刚柔、进退、时位 | 不能只摘华丽词句 |
| 自然物候 | 运动、节奏、形态 | 避免满门风花雪月 |
| 职业生活 | 工具、经验、身体技能 | 要尊重真实劳动逻辑 |
| 动物身体 | 蓄势、扑咬、缠绕、感官 | 不要只取威猛动物 |

### 4. 名称与动作映射

检查：

```text
删去招名，只看动作
→ 是否仍能猜到名称所属的意象家族
```

若完全不能，名称与机制可能脱节。

### 5. 门派内部的命名层次

创始祖师、实战弟子、文雅宗师和市井后人可能给同门技巧取不同名字。允许历史层叠，不必保持过分统一。

### 6. 雅俗反差

粗朴名称可以对应精妙武学，华丽名称也可能被人物用得生硬。雅俗属于命名者身份，不等于技术等级。

### 7. 改名必须改变理解

把文雅原名改成顺口俗名，可能突出动作画面；把敌人蔑称改为正式名，可能恢复技术来源。只有换字、没有理解变化，不值得写。

## 十、器物与地点命名

### 1. 器物名先服从使用者

匠人按材料与工序叫，主人按情感叫，江湖按效果叫，敌人按恐惧叫。同一器物可以有多个名字，但需要明确使用群体。

### 2. 宝物不必都叫“神、玄、天、龙”

具体材料、旧用途、声音、缺陷和来源更可信。名称越夸张，越需要公共事迹支持。

### 3. 地名的三层

```text
官名：行政与制度
本地名：地形、生产、事故、方言
江湖名：传闻、危险、著名人物或事件
```

外来人物可能只知道官名，本地人只用俗名，由此自然产生信息差。

### 4. 地名要能落回地形

“回声峡”应真的有声音传播规律，“三汊渡”应影响路线选择。不能只有诗意，没有空间机制。

### 5. 名称会随历史改变

政权改名、灾难留下俗称、英雄事件覆盖旧名、禁忌导致避讳。旧地图和老人仍可能保留旧称，形成线索。

### 6. 器物名称与生命周期

名称改变时同步检查：物件是否换主、功能是否暴露、公共评价是否变化。详细账本见 `object-lifecycle.md`。

## 十一、章回题目

### 1. 题目不是摘要

章名应成为读后可用的检索钩，而不是列出本章所有事件。

### 2. 六种题目中心

| 类型 | 作用 |
|---|---|
| 人物／群体 | 标记关键登场或身份中心 |
| 地点／空间 | 标记无法替换的舞台 |
| 器物／文本 | 标记跨章目标或回收 |
| 动作／困局 | 标记本章独特事件 |
| 关系／约定 | 标记情感与义务变化 |
| 命题／判断 | 标记价值冲突或终局认识 |

### 3. 四字结构的内部变化

可用但不必局限于：

```text
偏正：荒城夜雨
主谓：孤灯照骨
动宾：误启铜函
并列：新盟旧约
地点句：古渡桥头
人物句：雪岭遗民
```

形式整齐，语法应轮换，避免四十章全是“形容词＋名词”。

### 4. 不提前泄露关键答案

题目可以提出谜面、物件或公共称呼，避免直接写出本章末才确认的凶手、血缘或背叛。

### 5. 题目应来自正文

最好能在正文中找到实际场景、动作、物件或关系依据。纯粹漂亮而正文没有落点的题目，会像另配的诗签。

### 6. 全书题目要轮换焦距

```text
大景与小物
群体与个人
动作与静态
现实地点与文化专名
外部危机与内部判断
```

连续多章采用同一类型时，读者会失去章节轮廓。

## 十二、音形、长度与记忆

### 1. 可呼喊测试

姓名、绰号和招式需要在对白中自然说出。连续生僻字、同调字或拗口复辅音会降低现场可信度。

### 2. 相邻人物防碰撞

同场主要人物避免：

- 同姓又同尾字；
- 相同声母韵母组合；
- 都是三字文雅名；
- 绰号共享同一核心名词；
- 字形过近，电子阅读难辨。

### 3. 轮廓差异

长篇人物表需要长短、雅俗、汉名与音译、正式名与俗号相互交错。记忆来自差异，不是所有名字都完美对仗。

### 4. 高频词预算

“天、玄、神、龙、风、云、月、影、血、魂”等高频幻想字，每个阵营只选少数真正属于自身语义场的词。跨阵营重复时应有不同解释。

### 5. 数字谨慎

数字能快速建立规模和群体，但需要保持人数、招数、席位和历史变化连续。名字中的数字不是随意增强气势的副词。

### 6. 生僻字门槛

只有当字义、时代、地域或原典确有必要时使用生僻字。首次出现可通过人物反应或简短释义帮助识读，不要连续安排多个需要注音的专名。

## 十三、名称的生命周期

名称也会像物件一样改变状态：

```text
命名
→ 小范围使用
→ 公共传播
→ 被本人接受或拒绝
→ 被敌人改写或冒用
→ 因行动获得新意义
→ 被继承、废止或留在传说中
```

### 1. 首次出现

先给当前场景需要的名称。人物已有多个名号时，只介绍眼前关系会使用的一个。

### 2. 认证

秘密本名、旧称、师门字辈或只有亲近者知道的称呼，可以证明关系。但认证还需语境、动作或第二项证据，避免一句名字万能开锁。

### 3. 称谓变化

从尊号到本名、从全名到乳名、从亲称到官称，都是关系变化。记录谁先改口、对方是否接受、旁人是否听见。

### 4. 旧名回返

旧名可以把人物拉回被压抑的身份，但不能自动完成感化。它只打开关系与记忆，人物仍需选择。

### 5. 死后与传承

人物死后，江湖可能只留下绰号，亲友坚持本名，官方改写称号，弟子继承席位。不同版本显示谁赢得了叙述权。

## 十四、语义密度与留白

### 1. 核心网络密，边缘命名疏

主角、核心门派和长期物件需要稳定语义网络；一次性店家、普通兵器和过路地点优先使用清楚通名。

### 2. 一场限制新增专名

一般场景一次引入一至三个需要记忆的新专名。群像登场时可增加，但应借动作、位置、外貌和群体结构分批介绍。

### 3. 先用通名，后给专名

读者尚不知道事物重要性时，可以先写“青竹杖、旧石阵、山后小潭”；等人物认出或功能显现，再给正式名称。

### 4. 不必解释所有词源

只解释会改变人物判断、身份、动作或主题的来源。其余让语境与复现自然建立意义。

### 5. 允许历史杂质

真实命名系统会有旧名、误称、口音变体、创始人的任性和后人的简化。过度规则化会像游戏数据库。

## 十六、AI生成流程

### 第一步：提取世界语义源

从已经存在的地貌、生产、宗教、历史、阶层和冲突中提取词库。不要先凭空列“好听的古风字”。

### 第二步：分配命名者

为家族、师门、官府、百姓、敌人和人物本人分别确定文化边界与命名习惯。

### 第三步：建立二至四个语义场

核心阵营各有主场，另留一个全书共享的历史或主题场。避免每个阵营都使用相同风月词。

### 第四步：先写无专名设计

对人物写出身与命名期待；对武学写动作机制；对地点写地形功能；对器物写材料与用途。专名随后生成。

### 第五步：每项生成多种来源方案

至少比较：生活直称、文化用典、公共绰号三种方向。不是比较同一组华丽字的排列组合。

### 第六步：选择名称并登记关系

记录命名者、使用者、拒用者、词源、语义场、机制映射和首次公开位置。

### 第七步：做音形与碰撞测试

把同场人物和高频术语连续朗读，检查相似声母、韵母、尾字、字形和节奏。

### 第八步：安排首次出现

决定先出现通名、正式名还是绰号；由谁说出；是否需要最低释义；读者是否应立即知道词源。

### 第九步：安排变义

至少为核心名字、核心称号或章回题目中的一个设置行动回收。不要让所有名字都承担主题。

### 第十步：全书审计

检查专名密度、阵营区分、数字连续、译写一致、称谓权限和章名焦距轮换。

## 十七、改写与诊断

### 把随机古风名改成语义网络

原始方案：

> 山门叫玄霄宫，掌法叫流云幻月掌，宝剑叫九天龙吟剑，弟子名字都带“风”。

问题：四个名称来自互不相干的幻想高频词，既不对应山门生活，也不对应动作机制。

改写步骤：

1. 确定山门建在盐碱河湾，以护送夜船为生；
2. 提取灯火、浅滩、逆流、盐霜和纤绳等生活词源；
3. 把掌法机制写成借对方前冲之力横向卸入；
4. 由船工弟子使用直白俗称，由后来的文士掌门补正式名；
5. 让地点、行话、武学和人物比喻共享“渡与回流”，而非共享同一个字。

### 十一问诊断

1. 谁取了这个名字？他的知识足够吗？
2. 名称首先能否清楚指称并与相邻名称区分？
3. 它来自世界已有的哪项生活、历史或文化？
4. 同一阵营有哪些家族相似，又有哪些个人差异？
5. 武学、器物或地名是否对应实际机制？
6. 自称、他称、尊称和蔑称是否被混用？
7. 人物多个名字是否按关系逐层出现？
8. 外族名与跨语际写法是否尊重其体系并保持一致？
9. 核心名称是否有行动或关系上的变义？
10. 章名能否召回本章独特内容而不提前泄底？
11. 删去典故解释后，名称是否仍然可用、可记、可说？

### 交换测试

把甲门派的武学名换给乙门派。若不改动作、价值和场景也完全成立，两边尚未形成专属语义系统。

### 去名测试

隐去专名，只读人物动作、组织生活和空间规则。若无法反推任何意象家族，名称可能只是贴纸。

### 名称地图测试

把核心专名画成节点关系：若每个名字都只连向“很厉害、很古雅”，网络无效；若能连向命名者、生活方式、动作机制、人物关系和回收场景，网络才在工作。

## 十八、常见失败

### 1. 生僻字竞赛

每个专名都用难认字。修正：核心名称优先清楚可说，生僻字只在文化与地域确有必要时使用。

### 2. 风花雪月随机拼接

所有门派都从同一古风词库抽字。修正：先从生活、地貌、职业与思想建立各自语义源。

### 3. 名字直接宣布性格

善人必含仁义，恶人必含毒煞。修正：名字记录命名者期待或公共评价，允许人物证明、背离或重写它。

### 4. 同门只是机械复字

所有人共享一个字，却没有其他文化、能力或代际联系。修正：共享格式之外建立师承、命名者和语义逻辑。

### 5. 绰号塞满信息

一个别号同时写兵器、地域、外貌、性格和战绩。修正：选择一个清楚轮廓，让行动补足其余部分。

### 6. 拿到专名就知道一切

人物听见一个秘密名字便推知完整真相。修正：把名字当认证线索，与语境、关系记忆和独立证据合拢。

### 7. 招式换名不换动作

华丽名称与机制无关。修正：先写无专名动作，再从运动、时位和门派词源反推。

### 8. 招招报号

普通过渡动作也有四字招名。修正：只命名教学地标、战术分支和重要回收动作。

### 9. 门派名不进入生活

名称来自山海，成员生活和武学却与山海无关。修正：让地貌影响交通、资源、组织和身体技能。

### 10. 外族名汉诗化

所有族群都用同一种汉语古典审美。修正：尊重各自命名结构，区分本族名、译名、汉名和官号。

### 11. 一次倾倒所有名号

人物登场便列本名、字、号、法名、官职和外号。修正：按当前关系和信息权限逐层开放。

### 12. 过度规则化

每个名字都能严丝合缝解释主题，像数据库而不像社会。修正：保留俗称、误名、旧名和命名者的偶然选择。

### 13. 章名只有气氛

题目很美，正文没有对应实体、行动或命题。修正：选择本章真正独特且读后可召回的锚点。

### 14. 复制标志性词库

沿用参考作品已有的方位尊号、经典招名、花海乐曲或著名门派构词。修正：只迁移“统一槽位、机制映射、文化归属”的方法，重新从原创世界提取词源。

## 十九、可直接交给AI的指令

```text
为原创武侠项目设计或检查名称时，不从通用古风词库随机拼字。先从世界已有的地貌、生产、职业、宗教、历史、阶层和价值冲突中提取语义源，再为家族、师门、官府、百姓、敌人和人物本人分配不同命名权与文化边界。

对每个重要专名记录：类别、命名者、实际使用者、拒绝使用者、字面意义、文化来源、所属语义场、与实际动作或空间机制的映射、首次公开位置、其他称呼、知识权限、碰撞风险和计划变义。

人物姓名要区分命名者期待与人物实际人生；本名、乳名、字、法号、官称、绰号和化名按关系逐层开放。群体称号使用统一槽位加成员差异，不为凑齐网格临时造人。外族名尊重本族结构，区分音译、本族名、汉名和官号。

武学先写无专名的身体部位、运动路径、力量特征、使用场景和思想来源，再反推总名与关键招名。名称必须能映射动作原理；不是每个动作都要报号。门派、器物和地点名称要进入真实生活、材料、地形、组织规则与人物语言。

章回题目选择一个读后可召回本章的具体人物、地点、器物、动作、关系或命题，不写摘要，不提前泄露结尾答案，并在全书范围轮换焦距和语法。

完成后做可呼喊测试、相邻名称碰撞测试、门派交换测试和去名测试。若名称换给任何阵营仍成立，或去掉名称便看不出任何动作与生活逻辑，重新建立语义网络。只迁移命名方法，不复用参考作品的角色、门派、招式、宝物、专名或标志性词库。
```
