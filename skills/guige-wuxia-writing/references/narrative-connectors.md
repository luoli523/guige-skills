# 金庸写作风格卡·连接词与叙事开关

本模块由 `SKILL.md` 按任务类型加载。

## 一、核心结论

连接词不是表面的古风装饰，而是句子内部的叙事开关。它们负责告诉读者：

- 镜头现在转向哪里；
- 人物知道了什么；
- 原计划是否仍有效；
- 当前内容是事实、推断还是解释；
- 动作是在继续、转折、加速还是收束。

使用原则：先确定叙事功能，再选择词。不能为了“像武侠”而随机加入“当下、哪知、忽见”。

## 三、镜头开关

### 只见

功能：将注意力明确交给一个新对象或细节。

```text
观察位置 → 只见 → 总体轮廓 → 局部细节
```

适合首次揭示，不宜每个名词前都用。

### 但见

功能：强调所见场面，常带较宽幅度或连续景象。

```text
人物纵目望去，但见A、B、C……
```

### 眼见

功能：不是单纯看见，而是局势正在迫近、即将完成。

```text
眼见敌人逼近／兵器将到／天色将晚
```

### 却见

功能：视觉结果与此前预期不同。

### 忽见

功能：事物突然闯入画面，使静态观察转为事件。

## 四、感官触发开关

### 只听

主动或持续听见，将镜头暂时移到声音。

### 忽听

声音从画外突然闯入。适合黑夜、树林、墙外、门外和未知来者。

### 只觉、但觉

进入身体或模糊主观感受，不一定立刻知道原因。

### 忽觉、突觉

身体比意识更早发现异常，适合暗袭、点穴、毒性和内伤。

典型组合：

```text
待要A，突觉B，已被C。
```

## 五、时间与行动开关

### 当下

功能：结束判断、说明或犹豫，把叙述拉回当前行动。

```text
心想／判断A，当下B。
```

不等于现代口语中的“现在”。它更像“决定既成，立刻执行”。

### 便

功能：前一条件自然导向下一动作，语气比“立即”平顺。

```text
若A，便B；见A，便B。
```

### 便即、立即、立时

功能：提高动作紧密度和速度。

- 便即：承接前因并迅速执行；
- 立即：明确迅速；
- 立时：结果当场显现。

### 随即、跟着、接着

功能：动作链顺序推进。

### 于是

功能：前一段理由或局势产生一个较完整的行动结果，语气比“便”更有总结性。

## 六、预期与反转开关

### 却

最灵活的局部转轴，可连接：

- 行动与相反结果；
- 外貌与真实能力；
- 说话与内心；
- 一人与另一人；
- 本应发生与实际发生。

“却”不一定是大转折，更多是句内轻微偏转。

### 可是、但、只是

- 可是：明确对立；
- 但：简洁转折；
- 只是：承认前项，同时指出限制或保留。

### 哪知

功能：人物已有打算、判断或期待，但事实使之落空。

```text
人物本以为A，哪知B，竟C。
```

### 岂知

与“哪知”相近，但惊异和反常程度更强，语气也更古雅。

### 不料

更偏事件叙述层面的意外结果，不一定紧贴某个人物的主观预期。

### 饶是

先承认人物能力或条件很强，再写仍然无法避免的结果。

```text
饶是A，也／仍B。
```

## 七、心理开关

### 心想、心道

- 心想：进入人物较完整的判断；
- 心道：更接近一句人物内部说出的话，声口更明显。

### 寻思、思量

表示判断尚在形成，适合权衡。

### 转念

人物否定或修正刚才的第一反应。

```text
本欲A，转念一想B，于是C。
```

“转念”是聪明、克制或经验丰富人物的重要思维开关，但不能人人滥用。

### 心念一动

线索突然组合成新方向，通常立刻引发动作或问题。

### 料想、料知、想是、多半、想来

标记人物推断，不等同作者确认。

模糊度大致可理解为：

```text
料知（把握较强）
→ 料想／想来
→ 多半
→ 想是（保留更多）
```

具体强弱仍需服从语境。

## 八、因果与揭示开关

### 原来

核心功能是回溯性揭示：先给结果，后补原因。

```text
异常现象A；原来B。
```

三种身份必须区分：

1. 叙述者确认事实；
2. 人物心中的推断；
3. 对白中的解释版本。

后两者未必可靠。

### 只因、因为

提出原因。“只因”更紧凑，常把注意力集中到决定性原因。

### 兼之、加之

补充第二项条件，形成累积因果。

### 是以、因此、所以

- 是以：古雅、凝练，适合叙述；
- 因此：较中性；
- 所以：对白中更自然。

### 这才、才知、方知

表示事实早已存在，但行动或理解到此刻才完成。

### 其实

用于校正表面事实、人物自我认识或叙述预期，常带轻微反讽。

### 要知、须知

说书人暂时出面，补充当前行动必需的武理、历史或规矩。解释后应立即回到现场。

## 九、反应开关

### 忙、急忙

外部刺激后立即作出有目的的应对。

### 不禁、不由得

反应并非人物主动选择，适合惊讶、感动、羞愧、恐惧与发笑。

### 竟、居然

结果超过人物或常理预期。“竟”较短促，“居然”强调判断中的意外。

## 十、递进与时间流动

### 渐渐、慢慢

状态缓慢变化。

### 愈来愈、越来越

连续增强。

### 到后来

递进链的后段或最终状态。

### 过了一会、隔了半晌、不多时

既表示时间，也调整段落呼吸。

常用链条：

```text
初时A，渐渐B，到后来C。
```

## 十一、收束开关

- 终于：过程完成；
- 就此：状态从此固定或事件到此结束；
- 再也：越过不可恢复的界线；
- 已自、早已：结果在人物察觉前完成；
- 仍是、依然：经历变化后某种状态未改；
- 这才：延迟后完成动作或理解。

## 十二、常用组合链

### 1. 感知行动链

```text
忽听A → 心中一凛 → 忙B → 只见C
```

### 2. 误判反转链

```text
只道A → 哪知B → 竟C
```

### 3. 判断执行链

```text
心想A → 转念B → 当下C
```

### 4. 先果后因链

```text
只见A竟B → 原来C → 是以D
```

### 5. 累积因果链

```text
只因A → 兼之B → 因此／是以C
```

### 6. 危机速度链

```text
正待A → 突觉B → 已被C → 哪知D
```

### 7. 递进链

```text
初时A → 渐渐B → 愈来愈C → 到后来D
```

### 8. 认知回收链

```text
先前不明A → 又见B → 心念一动 → 这才明白C
```

## 十三、可直接交给AI的指令

```text
将连接词当作叙事功能开关，不当作古风装饰。

1. “只见、但见、眼见、忽见”分别承担揭示、展开、迫近和突入，不随意互换。
2. “心想、料想、多半”表示人物认识，不自动等于客观事实。
3. “哪知、岂知”必须有明确的前置预期；“不料”必须有可辨认的常规结果。
4. “原来”放在异常现象之后揭示原因；不要提前说明机关。
5. “当下、便、随即”应推动具体动作，不可只用来装点句子。
6. 同一段避免连续重复相同开关；可以省略能由句序自然表达的连接词。
7. 每个转折、因果和递进都必须在逻辑上真实成立。
```

## 十四、检查清单

- 这个连接词承担什么功能？
- 去掉它以后逻辑是否仍完全相同？若是，可能多余。
- “哪知”前面是否真的存在人物预期？
- “原来”前面是否已形成疑问？
- “当下”后面是否有立即执行的动作？
- 人物推断是否被误写成作者事实？
- 一段中是否堆积太多“忽、却、便、竟”？
- 是否可以通过动作顺序代替显式连接词？
