# 文字的诵读感与声音结构

本模块研究文字念出口时的轻重、疾徐、复现、轮次和收音。`rhythm-and-prosody.md` 负责句子怎样切成语块，本模块进一步负责这些语块怎样形成可听见的波形。

## 一、核心结论

诵读感不是字面华丽，也不是每句四字化，更不是给散文强配平仄。它来自五件事同时成立：

```text
意义可切
＋轻重可辨
＋句法有复现和变化
＋声音推动镜头或关系
＋句尾落在具体结果
＝清楚、顺口、有记忆点的叙事声音
```

最小声音单位不是单个字，而是“一个意义动作形成的语块”。一个好语块通常包含：

```text
轻拍入口｜一至两个内容重音｜明确落点
```

例如：

```text
却见｜门外那人｜已经走远
```

“却见”负责转向，读得轻；“门外那人”建立对象；“已经走远”落到不可追回的结果。

## 二、全书语料观察

### 1. 轻拍虚词密集

全书字符串粗检：

| 词 | 粗略次数 | 声音功能 |
|---|---:|---|
| 只 | 4084 | 收窄注意或限制条件 |
| 又 | 2916 | 追加一拍、复现或反复 |
| 已 | 2647 | 把动作推向完成状态 |
| 却 | 2231 | 逆转预期，形成弱拍转轴 |
| 正 | 1267 | 悬起一个尚未完成的动作 |
| 便 | 1096 | 顺势进入下一动作 |
| 忽 | 1085 | 突然切入新刺激 |
| 才 | 887 | 延迟后落到结果 |
| 当下 | 513 | 从判断返回行动 |
| 哪知 | 240 | 翻转前一预期 |

这些词通常不承担句子主重音。它们像鼓点之间的轻拍，帮助内容词自然进场。

### 2. 复现多于押韵

常见复现结构包括：

- 又……又……；
- 越……越……；
- 一面……一面……；
- 忽……忽……；
- 既……又……；
- 先……再……；
- 初时……渐渐……到后来……。

它们的声音效果来自句法骨架重复，最后一项发生意义变化。散文的音乐性主要是“相似中有推进”，不是句末强押韵。

### 3. 叠词延长感知

粗检中，“轻轻”约181次、“慢慢”约139次、“悄悄”约70次、“隐隐”约68次、“渐渐”约67次。

叠词不是单纯修饰：

- 动作叠词放慢身体；
- 声音叠词拉远距离；
- 状态叠词延长观察；
- 认知叠词表现迟迟不能落定。

### 4. 方向结果形成自然句尾

把全文按句末粗略拆分，常见双字收尾包括：

- 出来约157次；
- 起来约154次；
- 出去约111次；
- 过去约94次；
- 下来约92次；
- 过来约73次。

方向补语同时完成三件事：交代动作结果、建立空间、给声音收口。因此叙事句常比抽象评价更容易念稳。

### 5. 对白构成口头表演

粗检中，“说道”约1008次、“笑道”约900次、“叫道”约754次、“喝道”约269次、“问道”约264次；“接口道”“话未说完”“一言甫毕”等标记负责抢话、打断与交棒。

文本不是一条单声道旁白，而是叙述、人物说话、听觉反应不断交替的口头场面。

### 6. 声音直接组织镜头

“只听”约383次、“忽听”约196次、“听得”约557次。声音常先于来源出现：

```text
先听见
→ 判断远近、方向或人物
→ 声源进入画面
→ 现场行动改变
```

所以声音不仅制造气氛，也承担转场和信息控制。

以上均为对电子文本的字面粗检，只用于识别趋势，不作为创作配额。

## 三、五层声音结构

### 第一层：字词轻重

重音优先落在：

- 具体人物或物件；
- 关键动作；
- 异常状态；
- 方向与结果；
- 否定和对比的核心词。

弱拍通常由：

- 连接词；
- 时态和完成词；
- 代词；
- 引导感知或判断的短词；
- 不承担新信息的称谓。

不要给每个四字词同等重音。朗读时若所有词都很“响”，实际上没有重音。

### 第二层：语块音步

语块按意义而非固定字数形成音步：

```text
轻入口｜核心动作
主体｜动作｜结果
感知｜异常细节
条件展开｜短句裁断
```

四至八字常见，是因为这一长度容易容纳一个完整动作或判断，并非必须凑足。

### 第三层：句子波形

一个叙事句通常具有三种位置：

```text
起：建立对象或悬起动作
转：加入阻力、异常或判断
落：动作完成、认知改变或状态静止
```

句子不是把信息平均铺开，而是把最重要的词留在转折与落点。

### 第四层：对白轮次

人物每说一句，都向下一句施加压力：

```text
提问 → 回避
命令 → 反问
试探 → 装傻
长解释 → 一字否决
称谓呼叫 → 动作回应
```

轮次之间的长短反差，会比每句内部押韵更有戏剧声音。

### 第五层：段落与场景弧线

整段声音通常经历：

```text
建立常速
→ 复现加压
→ 短句或声响破拍
→ 动作/对白高潮
→ 降速
→ 静态收音
```

所有句子都短促会疲劳，所有句子都舒缓也会失去牵引。

## 四、十二种声音机制

### 1. 内容词落重音

把一句话中真正改变画面的名词和动词留下，其余成分读轻。

```text
他原想再问｜门闩却在此时｜轻轻落下
```

重音不在“原想、却在此时”，而在“门闩、落下”。

### 2. 虚词作轻拍转轴

“却、便、又、才、只、已”适合放在语义转向前，但不可机械连续。

```text
预期A｜却｜事实B
条件完成｜便｜行动C
动作反复｜又｜出现新差异
等待延长｜才｜得到结果
```

删去虚词后若逻辑完全不变，它可能只是表面古风。

### 3. 单音节动词连击

危急动作使用短而具体的动词形成重拍：

```text
闪｜扣｜扭｜推｜退
```

每拍应改变空间、受力或控制权。连续列出同义动作只会像口令。

### 4. 方向补语收口

“进、出、上、下、开、回、住、倒、远”等结果词适合句尾：

```text
人从门内出来
刀被震得脱手飞去
脚步声在巷口停住
```

它们既有声音落点，也让读者知道动作最终到哪里。

### 5. 叠词延长一拍

叠词适合慢动作、远声音、弱光和迟疑：

```text
灯影微微一晃
脚步渐渐近了
他把信慢慢折起
```

一段选一类主要叠词。连续“轻轻、慢慢、悄悄、默默”会稀释力量。

### 6. 句法复现后变奏

先让读者听熟骨架，再在最后一次改变内容：

```text
第一次是试探
第二次仍是试探
第三次句式相同，结果却越过底线
```

复现必须带来递进、反差或回环。原样重复只适合表现执念、恐惧或认知冻结。

### 7. 长铺短断

让长句积累条件，短句负责裁断：

```text
他把一路见闻、众人疑点和自己的推断逐层说完。老人只道：“不对。”
```

短句因为前面有蓄势才有重量。全文都短，裁断便不再突出。

### 8. 问答回声

提问中的关键词在回答中复现，但意义发生偏转：

```text
“你还回来么？”
“该回来时，自会回来。”
```

回声帮助读者记住核心词，也暴露人物是在回答问题，还是躲开问题。

### 9. 打断与抢拍

用话未说完、接口、突发声响或动作夺走话轮：

```text
甲的长句尚未落地
→ 乙抢过关键词
→ 外部声响再打断乙
→ 权力或信息发生变化
```

打断必须有叙事收益，不能每次只用来制造热闹。

### 10. 拟声词作为接触点

拟声词最适合标记：

- 两件物体真正接触；
- 原本看不见的动作产生结果；
- 安静被突然打破；
- 一连串动作中最关键的一击。

常用结构：

```text
动作逼近｜声响｜物理结果｜人物反应
```

避免给每一拳、每一步、每次拔刀都配声音。

### 11. 先声后形

让声音先进入感知，再揭示来源：

```text
忽听远处一声短哨
→ 人物判断方向
→ 哨声变近或换位
→ 人或物才进入视野
```

适合夜景、埋伏、高手登场、追兵逼近和身份误认。

### 12. 静默形成负音

“不语、无声、听不见”不是没有声音，而是读者预期中的声音没有出现。

```text
问句落下
→ 应有回答
→ 只有环境声或身体小动作
→ 沉默取得意义
```

静默前要建立声音预期，静默后要改变关系或行动。

## 五、六类场景的声音设计

### 1. 景物展开

声音倾向：舒缓、由远及近、叠词适量、尾句落到人物或动作。

```text
长视野｜持续声响｜局部颜色或运动｜人物进入
```

景物段不能一直处于同一音量。最后应有一个可执行的叙事入口。

### 2. 日常叙事

声音倾向：中速、动作清楚、方向补语自然、少量口语虚词。

重点是顺口而不显技巧，让读者毫不费力地跟上人和物。

### 3. 武打与追逐

声音倾向：短动词重拍与较长受力解释交替。

```text
出招短拍
→ 接触声或方向变化
→ 较长句解释局势
→ 再用短句改变控制权
```

只有短拍会像招式目录；必须插入空间、受力和判断。

### 4. 机锋对白

声音倾向：问答短、关键词复现、句长反差、抢话频繁。

聪明不等于长篇妙语。真正的机锋往往用对方刚说过的词反转框架。

### 5. 情感场景

声音倾向：停顿增多、称谓突出、句法破裂、环境声进入空白。

强烈情感可以突然变慢或冻结，不必总靠感叹号升高音量。参见 `emotional-subtext.md`。

### 6. 解释与回顾

声音倾向：较长因果链，中间设明确路标，结尾用短句返回现场。

```text
起因｜中间变化｜人物误判｜真实结果。门外忽然有人咳了一声。
```

解释不能一直保持同一长音；需要用具体声响、动作或问答重新开门。

## 六、对白的口腔节奏

### 1. 一句话只保留一个主要口头动作

人物是在问、拒绝、拖延、承认、命令还是讥刺？一句对白同时做太多事，念起来就像书面说明。

### 2. 称谓是起拍器

称谓放在句首，会先确定关系和音量：

```text
“师父，……”
“姑娘，……”
“姓沈的，……”
```

省去、恢复或更换称谓，本身就是节奏变化。不要每句话都重复称谓。

### 3. 问句必须有不同形状

区分：

- 求事实：“谁来了？”
- 求确认：“是他，是不是？”
- 反问：“这也算守信么？”
- 逼供：“刀在哪里？”
- 自问：“我还能去哪儿？”

不同问句应产生不同停顿与回答压力。

### 4. 回答不必语法完整

自然口头轮次允许：

- 一个词；
- 重复问题中的关键词；
- 用动作回答；
- 回答前一个隐藏问题；
- 故意答非所问。

但省略的信息必须能从现场恢复，否则只是含糊。

### 5. 笑、叹、喝是发声方式，不是人物标签

同一个“笑道”可以是亲近、掩饰、压迫或自嘲。发声动词必须与台词策略一致，不可轮流套用。

### 6. 让人物拥有个人收音

为主要人物限定：

```yaml
oral_profile:
  default_tempo: 快 | 中 | 慢
  stress_preference: 动作 | 事实 | 称谓 | 判断 | 利害
  pause_style: 沉默 | 重复 | 改口 | 反问 | 动作代答
  sentence_tail: 决断 | 询问 | 留白 | 解释 | 命令
  interruption_style:
  laughter_or_sigh:
  pressure_change:
```

人物在压力下应变调，但仍能听出原有声音系统。

## 七、段落与场景的声音弧线

### 1. 基准拍

先用两三句建立正常速度。没有基准，突然变快或变慢就无法被听见。

### 2. 加压

通过以下方式加压：

- 句子逐渐缩短；
- 同一结构递进复现；
- 回答越来越晚；
- 环境声越来越近；
- 方向词快速切换；
- 话轮被不断打断。

### 3. 破拍

用一个异常短句、突发声音、长沉默或意外长句打破基准。

破拍处应对应事实、关系或控制权变化。

### 4. 高点

高潮不一定最大声。可以是：

- 一句终于说出的真话；
- 一个名字；
- 一声接触响；
- 完全没有回答；
- 重复到第三次时改变的最后一个词。

### 5. 收音

高潮后降低信息密度，把句尾落到：

- 动作完成；
- 人物离开；
- 声音消失；
- 物件静止；
- 一句短判断；
- 未获回答的问题。

收音后不要立刻解释高潮“意味着什么”。

## 八、标点、停顿与换气

### 逗号：小换气

只在意义块完成时换气。不要因为句子长便均匀撒逗号。

### 句号：换拍或落地

主体目标、动作方向、关系状态或观察焦点发生变化时，用句号重新起拍。

### 冒号：打开另一副声音

用于引出对白、心语、口诀、书信或解释。冒号前应产生“接下来要听”的期待。

### 分号：保持骨架的并行

适合两组结构近似、意义对照的语块。普通动作不必为了古雅而使用分号。

### 问号：向下一轮施压

问号不是语气装饰。写下问号，就必须决定谁回答、怎样回避或为何没有回答。

### 感叹号：音量峰值

同一人物连续多句感叹会使峰值失效。真正强势的人物常用短陈述句下命令。

### 省略号：未完成的声音

只用于确实中断、迟疑或气力不继。不能把所有情感都写成省略号。

## 九、AI声音参数

这些是软参数，不是统计配额：

### 单句

- 每句设置一至三个主要重音；
- 长句内部使用三至六个意义语块；
- 避免连续四个以上等长、同构语块；
- 普通叙述优先让句尾落在动作、方向或状态；
- 抽象判断若必须出现，尽量不连续充当句尾。

### 句群

- 每两至四句形成一个小波形：展开、转折、落地；
- 连续短句之后补一处空间或因果；
- 连续长句之后用短动作、问答或声响截断；
- 复现结构通常两至三次，最后一次必须变奏。

### 对白

- 一轮只执行一个主要策略；
- 问答之间允许长短不对称；
- 关键词可复现，但整句不要原样复读；
- 动作插入应改变语气、关系或信息，不作无意义摆手点头；
- 发声动词优先使用最普通的“道、问、叫”，特殊动词只在声音方式确有作用时使用。

### 拟声与叠词

- 一个连续动作段只突出最关键的一至两个声音；
- 同一小段避免连续使用多个不同叠词；
- 拟声后交代物理结果，不能只制造漫画音效。

## 十、朗读编辑法

### 第一步：按意义切斜线

```text
他走到窗前／侧耳听了片刻／却只听见／檐水一滴一滴／落在空缸里
```

若切不开，说明句法承担了太多功能。

### 第二步：标重音

每句圈出一至三个必须听清的词。若圈出七八个，删减修饰或拆句。

### 第三步：标轻拍

检查“却、便、又、只、已、才”等是否真的转向。没有功能的删去。

### 第四步：检查语块长度变化

连续等长会像口号；短、中、长块应有自然交替。

### 第五步：检查句尾

把每句最后二至四字单独列出。若连续都是“的样子、的感觉、的情绪、的神色”，改成具体动作或状态。

### 第六步：检查复现

相同结构再次出现时，内容是否升级、转义或被打断？没有则删去一次。

### 第七步：真正念出来

朗读时标记：

- 被迫中途换气的位置；
- 舌头打结的位置；
- 不知道该重读哪个词的位置；
- 念完却不知道动作落在哪里的位置；
- 段落本应结束却仍在解释的位置。

### 第八步：盲听测试

不看文字，只听朗读，确认能否判断：

- 谁在行动；
- 动作方向；
- 哪一句发生转折；
- 对白由谁掌握主动；
- 段落在哪里真正结束。

## 十一、场景模板

### 模板A：由静入动

```text
持续而低的环境声
→ 人物小动作
→ 声音中出现不协调的一拍
→ 人物停住
→ 短句揭示新威胁
```

### 模板B：追逐加速

```text
中速建立方向
→ 短动作连续两三拍
→ 较长句说明障碍和距离
→ 一个声响标记接触
→ 短句改变领先者
```

### 模板C：机锋问答

```text
甲用长句设框
→ 乙复现一个关键词
→ 用短句反转
→ 甲抢话
→ 外部动作决定谁真正占优
```

### 模板D：情绪降音

```text
正常对话
→ 称谓改变
→ 回答缩短
→ 应有回答处沉默
→ 环境小声进入
→ 动作收束
```

### 模板E：解释后回场

```text
原因链分三层展开
→ 每层有清楚路标
→ 最终结论缩短
→ 现场声响或问句打断
→ 人物立即行动
```

## 十二、常见失败

### 1. 把平仄当散文公式

强行安排声调和押韵，语义因此变硬。修正：优先保证意义音步、重音和句尾结果；韵脚只在诗词、口诀和仪式化语言中突出。

### 2. 四字块排队

每块都整齐响亮，像宣传口号。修正：插入具体主体、单音节动作、延展说明和短应答。

### 3. 虚词古装化

“却说、当下、哪知、原来”密集出现，却没有真实转折。修正：给每个连接词标注功能，无功能即删。

### 4. 拟声词漫画化

拳拳有声、步步有响。修正：只保留改变局势或揭示看不见动作的关键声音。

### 5. 叠词糖浆化

慢慢、轻轻、悄悄连续使用，使所有动作失去重量。修正：一段选择一个需要延长的感知维度。

### 6. 句尾抽象化

连续落在“感到悲伤、显得紧张、十分震惊”。修正：落到身体、方向、动作结果或关系状态。

### 7. 全段同速

动作场景一直短，解释场景一直长。修正：建立基准、加压、破拍、收音的波形。

### 8. 对白书面化

每个人都说完整长句，轮次之间没有压力。修正：允许短答、复现、回避、抢话和动作回答。

### 9. 省略号泛滥

所有迟疑与悲伤都用“……”表示。修正：人物可通过重复、改称谓、沉默或做错动作表现中断。

### 10. 声音不改变镜头

写了风声、雨声、脚步声，人物却毫无反应。修正：声音必须改变注意方向、判断或行动。

### 11. 高潮后继续加码

关键短句之后又跟一段解释和三个感叹号。修正：降低信息密度，用动作、静默或声音消失收尾。

### 12. 为顺口牺牲人物

所有人物都说同样漂亮的机锋。修正：声音结构必须经过人物声口系统；笨拙、迟缓、断裂也可以有准确节奏。

## 十三、可直接交给AI的指令

```text
写作或改写时，把诵读感建立在意义语块、轻重重音、句法复现、对白轮次和具体收音上，不强行押韵或凑平仄。

1. 每个语块只承担一个主要动作、状态、感知或判断。
2. 每句设置一至三个主要重音，优先落在具体名词、动词、异常细节和结果上。
3. 将“却、便、又、只、已、才”等作为轻拍转轴；没有逻辑功能时删除。
4. 混合短、中、长语块。复现结构通常使用两至三次，最后一次必须递进、反转或中断。
5. 让动作句尽量落到方向、接触、停止或状态变化；避免连续用抽象评价收尾。
6. 对白按问答、回避、抢话和动作回应组织轮次，并服从人物专属声口。
7. 拟声词只标记关键接触或画外变化；声音出现后必须改变人物注意、判断或行动。
8. 每个句群形成“建立—转折—落地”的小波形；连续长句后用短动作或问答破拍。
9. 高潮后降低音量，以静默、动作完成、人物离开、物件静止或声音消失收音。
10. 写完按意义切斜线、标出重音并实际朗读；在换气困难、重音不明、舌头打结或落点含糊处重写。
```
