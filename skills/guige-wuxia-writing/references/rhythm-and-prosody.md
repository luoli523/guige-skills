# 金庸写作风格卡·节奏参数与诵读结构

本模块由 `SKILL.md` 按任务类型加载。

## 一、核心结论

文字的清楚与诵读感，不主要来自连续使用成语，而来自：

> 一个较长句子被切成若干意义自足、长度适中、重音清楚的语块；语块之间用轻巧连接词转向，最后落到一个动作、状态或判断上。

节奏单位是“语块”，不是“字数”。四至八字只是最常见的容器。

## 二、全书基础参数

正文语料统计：

- 汉字约774,468字；
- 句子约28,940句；
- 分句约111,441个；
- 平均句长约26.76字；
- 平均分句约6.95字；
- 四至八字分句约占59.57%；
- 完整四字分句约19,939个。

这些数字说明，文本不是以整齐四字句为主，而是以四至八字的弹性语块为主体，并混合短应答与长复句。

## 三、语块的功能类型

### 1. 锚定块

交代主体、地点、时刻或方位。

```text
这一日晚间｜江畔林中｜那白衣人｜船头之上
```

### 2. 动作块

一个主要动词加对象、方向或身体部位。

```text
伸手去接｜转身便走｜向后跃开｜一掌击出
```

### 3. 状态块

形成可独立感知的画面或身体状态。

```text
面色惨白｜呼吸急促｜默然不语｜心事重重
```

### 4. 判断块

人物或叙述者对事实的简短解释。

```text
心知不妙｜料来无碍｜显是中毒｜原来如此
```

### 5. 转轴块

改变语义方向。

```text
正待退开｜哪知此时｜转念一想｜便在此刻
```

### 6. 结果块

给动作或段落落地。

```text
跌倒在地｜再也不动｜终于消失｜无法可施
```

## 四、六种常见句内节奏

### 1. 三拍推进

```text
锚定｜动作｜结果
```

适合简洁叙述。

### 2. 四拍展开

```text
主体｜动作｜局部变化｜人物反应
```

适合外貌、景物和普通动作。

### 3. 判断行动链

```text
感知｜判断｜决定｜行动
```

适合心理、对白攻防和临场应变。

### 4. 长铺短收

前面用较长复句交代条件与变化，末尾用短语块落地。

```text
多项条件展开……｜当下转身便走。
```

### 5. 短促连击

连续短块提高速度：

```text
回身｜出掌｜相接｜一震｜倒退
```

适合危急攻防，但不能持续太久，否则像动作清单。

### 6. 递进复沓

```text
初时A｜渐渐B｜愈来愈C｜到后来D
```

适合伤势、内力、声音、距离和情绪变化。

## 五、不同内容的节奏差异

| 内容 | 倾向 |
|---|---|
| 对白 | 最短，允许一至三字应答、重复和中断 |
| 日常动作 | 分句短，动作次序清楚 |
| 身体反应 | 四至八字块密集，逐层递进 |
| 武打 | 句子较长，但内部由短攻防块组成 |
| 心理判断 | 句子较长，以条件和结论组织 |
| 镜头展开 | 较长，从整体扫到细节 |
| 因果解释 | 较长，形成小型证明链 |
| 段落收束 | 明显缩短，状态或动作落地 |

因此不能给所有段落统一句长。

## 六、建议给AI的软参数

以下是用于原创文本的校准范围，不是对原作的硬复制：

### 分句

- 主要分句：四至八字；
- 极短块：一至三字，用于应答、拟声、突发和落点；
- 延展块：九至十五字，用于必要说明；
- 一句话中至少混合两种长度，避免整齐划一。

### 句子

- 普通叙述：约十五至三十五字；
- 心理、镜头和因果链：可延展至三十五至六十字；
- 对白：常为三至二十五字，必要叙事性对白可更长；
- 高潮处允许长复句，但内部必须可清楚切分；
- 收束句宜比前一句短。

### 四字表达

- 一般长句中使用零至三个自然四字块；
- 不要求每句都有；
- 成熟四字词、自造状态块、动作结果块可以混用；
- 四字块之间必须有具体名词和动词支撑。

### 段落

原始TXT换行受下载格式破坏，无法可靠统计原版段落参数。因此不设机械段落句数，只使用功能规则：

- 一个段落围绕一个观察、动作、判断或回应；
- 焦点人物、时间、空间或行动目标改变时考虑换段；
- 收束后再开启下一刺激。

## 七、产生诵读感的声音手段

### 1. 叠词

用于持续、分布、颜色、声音和姿态：

```text
日日夜夜｜浩浩荡荡｜隐隐约约｜慢慢吞吞
```

叠词适合形成延长音感，但一段不宜连续堆积。

### 2. 对称与复现

```text
一时A，一时B
又是A，又是B
忽前忽后，忽左忽右
```

对称应对应真实的状态摆动。

### 3. 方向词

上、下、前、后、左、右、内、外能同时提供空间和节拍，尤其适合动作句。

### 4. 拟声词

拟声词相当于动作标点：

```text
声响｜接触结果｜人物反应
```

不要连续为所有动作配音。

### 5. 虚词轻拍

“便、却、又、仍、已、才、只”通常不承担重音，却帮助语块自然转向。重音应落在具体动作和结果上。

### 6. 句尾收音

句子常落在：

- 明确动作：转身出去；
- 身体结果：倒在地下；
- 静止状态：默然不语；
- 距离变化：越来越远；
- 认知结论：这才明白。

避免以抽象评价反复收尾。

## 八、标点与呼吸

### 逗号

切分连续语块，使复杂动作仍可朗读。

### 分号

适合并列两组较完整的条件、动作或对照。

### 冒号

引出人物心语、对白、列举或解释。

### 破折与省略

用于话语中断、迟疑和未说完，不作为普遍古雅标记。

### 句号

当动作目标、视角焦点或状态已经改变时，应结束句子，不要用逗号无限拖延。

## 九、语块编辑法

### 第一步：斜线切分

将草稿按意义切开：

```text
人物抬头一看／只见山路尽头／站着一个黑衣人／手中提刀／一动不动
```

### 第二步：检查每块功能

每块是否只有一个主体动作、状态或判断？

### 第三步：删除同义重复

例如身体已经“浑身发抖”，一般不必再说“心中非常害怕”。

### 第四步：调整长短

连续五六个四字块会过于整齐，应插入较短或较长块。

### 第五步：确定重音

朗读时每句应有一至三个主要落点，通常是动作、异常细节和结果。

### 第六步：短句收尾

若一段已经充分展开，最后一句应收紧，而不是再次解释主题。

## 十、可直接交给AI的节奏指令

```text
用意义自足的短语块组织句子，主要语块约四至八字，但不要机械凑字。

1. 每个语块只承担一个主体动作、状态、方位、判断或结果。
2. 长句内部必须能自然切成三至六个语块。
3. 混合极短、常规和延展语块，避免全段整齐四字化。
4. 对白与收束宜短；镜头、心理和因果可长，但要层次清楚。
5. 让重音落在具体名词、动作和结果上，连接词只负责轻转。
6. 使用适量叠词、对称、方向词和拟声词，不连续堆积。
7. 展开充分后，用较短的动作、状态或认知句收尾。
8. 写完后按语义斜线切分并朗读；若无法一口一块地读清，应重写。
```

## 十一、检查清单

- 长句能否切成清楚语块？
- 每块是否只有一个主要功能？
- 是否连续出现太多等长四字块？
- 是否有具体名词和动词支撑四字表达？
- 对白是否比叙述更短、更有停顿？
- 武打长句内部是否仍能辨认攻、防、接触和结果？
- 解释段是否在最后收紧？
- 句尾是否落到动作、状态或认识？
- 朗读时重音是否清楚？
- 是否把统计均值误当成每句硬指标？
