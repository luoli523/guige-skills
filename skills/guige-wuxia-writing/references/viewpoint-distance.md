# 金庸写作风格卡·叙述视角与距离伸缩

本模块由 `SKILL.md` 按任务类型加载；文化材料的叙事用法见 `culture-weaving.md`，秘密、误判、线索和读者认知的长期控制见 `information-control.md`。

## 一、核心结论

这种叙述不是固定不动的全知视角，也不是严格锁死在一个人物身上的限知视角，而是：

> 以外部动作作为默认叙述面，以人物感知作为入心入口，以短促判断作为近景，再迅速落回动作；说书人只在需要交代时间、揭示机关、补充常识或校正误判时暂时出现。

最常见的基本循环是：

```text
外部状态
→ 人物看见、听见或感觉到某物
→ 人物作出解释或推断
→ 产生即时情绪
→ 采取动作或说话
→ 镜头重新回到外部世界
```

这种写法兼具全知叙事的自由与现场叙事的紧迫感。

## 三、六级叙述距离

### D5：时代与时间俯瞰

用途：跨越数日、数月、数年，介绍时代局势、旅程和成长结果。

常用信号：

- 当时、其时、后来；
- 过了数日、如此过了半年；
- 自此、从此、不一日；
- 这一日、次日。

写法要求：

- 只交代会改变当前局面的信息；
- 压缩完成后尽快落到一个具体时刻；
- 用一个可见动作或突发声响结束概述。

```text
如此过了三月，人物已能完成某事。
这一日晚间，他正在某处，忽听……
```

### D4：场景全景

用途：交代地点、季节、天气、人群分布与主要空间关系。

典型顺序：

```text
大地域
→ 当前地点
→ 天时气候
→ 人群或建筑
→ 一个值得注目的局部
```

全景不是每章必用。若章节承接上回的同一动作，应直接续写；只有进入新地点、新时间或新场面时才重新建立全景。

### D3：外部动作面

这是默认叙述层。人物通过动作、姿态、对白和位置变化被看见。

原则：

- 没有必要进入内心时，就留在外部；
- 情绪先让身体、目光和动作承担；
- 多人物场面以这一层维持清晰；
- 武打、追逐和争执都以此层为地面。

### D2：贴身感知

通过人物的眼、耳、鼻、皮肤、痛觉和气息贴近现场。

| 信号 | 适合内容 |
|---|---|
| 只见、但见 | 有意识观察、画面展开 |
| 忽见 | 新物突然进入视野 |
| 眼见 | 局势正在迫近 |
| 只听 | 将注意力转向声音 |
| 忽听 | 画外事件突然闯入 |
| 只觉、但觉 | 身体或模糊感受 |
| 忽觉、突觉 | 身体比意识更早发现危险 |

贴身感知的价值，是把客观世界限制在人物此刻能够获得的信息内。

### D1：解释与推断

人物根据感知作出判断：

```text
可见事实
→ 料想、想是、多半、看来
→ 暂时结论
```

必须区分“人物看见的事实”与“人物给出的解释”。推断可以正确，也可以因为知识不足、偏见、恐惧或愿望而错误。

推荐写法：

> 他只见A，又听见B，料想C。

不要把C直接写成作者确认的事实，除非叙述者确实准备揭底。

### D0：直接心语

常用“心想、心道、暗想、寻思”进入。

直接心语的主要功能不是抒情，而是：

- 判断局势；
- 权衡利害；
- 回忆一条有用信息；
- 形成误判；
- 作出决定；
- 暴露人物不肯说出口的真实动机。

建议控制在一至三组短语块内，然后以“当下、忙、便、于是”等词返回行动。

## 四、叙述者覆盖层

叙述者不是距离阶梯中的固定一级，而是可以暂时覆盖任何一级。

### 1. “原来”：补上机关

```text
先给异常现象或结果
→ 人物或读者产生疑问
→ 原来……
→ 解释具体原因
```

应先让解释成为需要，再揭示原因。不要先说明机关，再让现象按说明发生。

### 2. “其实”：校正表面理解

```text
人物以为A
→ 其实B
```

适合揭示人物不了解自己的感情、误解对方动机，或让叙述产生轻微反讽。

### 3. “要知、须知”：补充必要常识

适合武理、历史、门派规矩和社会习惯。使用后必须迅速返回眼前行动。

### 4. 时间压缩

概括重复训练、旅程和局势变化。压缩结束时选择一个具体日期、声音、来人或意外作为重新入场点。

## 五、最重要的伸缩路径

### 路径A：由远至近

```text
地域和天时
→ 人群或建筑
→ 某个具体人物
→ 人物正在做的动作
→ 一个异常细节
```

适用于新故事、新地点和重大场面开端。

### 路径B：感知—判断—行动

```text
人物只见／忽听A
→ 心中一动
→ 心想或料想B
→ 当下／忙／便C
```

这是最常用、最值得AI默认采用的场景推进单元。

### 路径C：人物误读

```text
真实线索A、B
→ 人物受偏见或愿望影响
→ 得出合理但错误的C
→ 按照C行动
→ 后文由新线索或“其实”重释
```

误导应来自解释错误，不宜伪造前文事实。

### 路径D：心理被现实打断

```text
人物正在盘算A
→ 正要采取行动
→ 忽听／忽见／突然B
→ 原计划失效
```

此法可以防止心理段落拖沓，并使外部世界始终具有主动性。

### 路径E：先果后因

```text
出现不合常理的结果
→ 人物惊异或受制
→ 原来……
→ 揭示机关或高手动作
```

适合武打、暗器、机关和身份揭示。

### 路径F：视角交棒

```text
人物甲完成一个动作或一句话
→ 明确写出人物乙的姓名
→ 先写乙看见或听见什么
→ 再进入乙的判断
```

不可从甲的未说出口之念直接跳进乙的未说出口之念。

## 六、多人物场面的视角纪律

### 一个节拍只能有一个内心主人

同一个事件节拍中，只选择一名人物承担D2至D0的贴近视角。其他人物通过动作、神态、对白表现。

### 切换必须有明确锚点

安全锚点包括：

- 新段开头直接写人物姓名；
- 该人物受到攻击、被问话或开始行动；
- 前一人物的动作明确结束；
- 镜头先回到外部场面，再进入新人感知。

### 切换应有叙事收益

只有在下列情况下才换视角：

- 新人物知道关键秘密；
- 新人物将作出决定；
- 同一事实在他眼中有不同意义；
- 需要展示误会或利益冲突；
- 原视角人物无法感知即将发生的事情。

如果切换只为补一句“他也很惊讶”，应留在外部写其神态。

## 七、人物心理句的使用规范

### 心理必须由现场触发

优先使用：

```text
看见A → 想起B → 判断C → 决定D
```

避免人物无缘无故停下来总结自己的性格、人生和主题。

### 心理必须产生动作

心理段结束后，应至少改变一项：

- 下一动作；
- 对某人的态度；
- 说话策略；
- 风险判断；
- 读者对事实的理解。

### 心语要保持人物声口

直接心语可以不合逻辑、偏执、朴素或自欺。它不是作者替人物撰写的分析报告。

### 长心理应分段落地

```text
一段判断
→ 一个小动作或感官变化
→ 再想下一层
```

避免连续数百字不接触外部世界。

## 八、可直接交给AI的写作指令

```text
采用第三人称伸缩式全知视角：

1. 以外部可见动作和对白作为默认叙述面。
2. 每个场景节拍选择一名焦点人物，不同时进入两个人的内心。
3. 进入人物内心前，先给出他实际看见、听见或感觉到的触发物。
4. 严格区分客观事实、人物推断和叙述者确认；人物推断允许出错。
5. 心理活动以判断、权衡、回忆线索和决定行动为主，通常控制在一至三组短语块。
6. 心理结束后，用动作、对白或突发感知返回外部现场。
7. 新地点或新时间可从全景逐步推近；承接上一场动作时直接续写，不重复建立背景。
8. 多人物场面换视角时，先写出新焦点人物姓名及其感知，再进入其想法。
9. “原来”用于现象之后揭示机关；“其实”用于校正人物或表面理解；“要知、须知”只补充当前行动必需的常识。
10. 不要让叙述者提前说明本应由悬念、误判或行动揭开的信息。
```

## 九、六个AI场景模板

### 模板1：新场景推近

```text
【地域】A地如何。
【天时】正是B时节。
【人群】某处聚着C类人。
【焦点】其中一人正在D。
【异常】忽听／忽见E。
```

### 模板2：即时行动

```text
人物只见A，心中B，料想C，当下D。
```

### 模板3：误判推进

```text
人物看见A，又发现B，心想：“多半是C。”于是D。
```

### 模板4：心理中断

```text
人物正盘算A，要待B，忽听C，忙D。
```

### 模板5：机关揭底

```text
只见A竟然B，众人无不惊异。原来C，因此D。
```

### 模板6：安全换焦

```text
甲说完／做完A。
乙见到B，心中C，随即D。
```

## 十、质量检查清单

- 当前节拍的焦点人物是谁？
- 读者此刻只能获得哪些感官信息？
- 哪些是事实，哪些只是人物推断？
- 心理活动是否由现场触发？
- 心理活动是否改变了后续行动？
- 是否在一个节拍内进入了两个人的内心？
- 换视角前是否写明新人及其感知？
- 是否过早使用叙述者解释破坏悬念？
- 时间概述之后是否落回具体场景？
- 场景承接紧密时是否重复介绍地点和人物？
- 能否把一句抽象心理改成身体反应或动作？
- 段落最终是否回到一个可见、可听或可执行的东西？

## 十一、常见失败

### 1. 无锚点跳心

甲想完一件事，下一句直接写乙也在想另一件事，读者失去视角立足点。

### 2. 作者替人物知道太多

人物没有获得线索，却准确解释远处阴谋和他人动机。

### 3. 先解释、后发生

先说明机关原理，再把机关运行一遍，现场惊奇被提前消耗。

### 4. 心理成为论文

人物长篇分析主题，却没有感官触发，也不改变动作。

### 5. 全景反复重置

每到新段都重新介绍天气、环境和人物站位，破坏连续动作。

### 6. 所有情绪都进入内心

惊讶、羞愧、害怕和爱意全部直接说明，外部动作面消失。情感显影方法见 `emotional-subtext.md`。

### 7. “只见、心想、原来”机械连用

这些词是视角开关，不是必须重复的表面风格。先确认叙事功能，再选择是否使用。

## 十二、后续可补充的reference

- 各类视觉、听觉、触觉视角信号词；
- 直接心语与间接心理叙述例型；
- 多人物场面的安全换焦案例；
- 人物误判与叙述者校正案例；
- 章节开头由远至近、直接续接和突发入场的分类样本；
- 长时间压缩后重新落地的场景样本。
