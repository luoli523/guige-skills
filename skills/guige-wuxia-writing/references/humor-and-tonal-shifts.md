## 一、核心结论

诙谐不是插入一个笑话，而是人物按照自己的性格解决现场问题时，产生了两个同时成立、彼此不协调的意义框架：

```text
真实压力或明确任务
＋人物特有的欲望、盲点、身份或语言策略
＋另一个人不同的理解框架
→ 预期落空、身份倒置或字面错位
→ 关系、信息或行动发生变化
```

情绪换挡也不是作者宣布“众人转忧为喜”，而是现场出现了一个足以改变人物注意、身体和行动方式的铰链：

```text
原有主调
→ 异调信号进入
→ 具体铰链触发
→ 人物行为和句法改变
→ 新主调建立
→ 旧情绪留下余味
```

两个原则必须同时成立：

1. **诙谐要推动场景。** 删除笑点后，关系、信息、权力或行动应至少有一项不同。
2. **换挡要保留余味。** 新情绪接管场景，但前一种情绪不应像开关一样消失。

因此，本模块的目标不是让文本“更搞笑”，而是让长篇拥有呼吸、反差、人物亲密和情绪层次。

## 二、全书语料观察

对全文TXT进行字符串粗检，笑的动作远多于直接宣布“这是笑话”：

| 信号 | 粗略次数 | 主要可能性 |
|---|---:|---|
| 笑道 | 784 | 亲近、试探、掩饰、讥刺、压迫或真笑 |
| 一笑 | 213 | 短促关系回应或情绪校准 |
| 大笑 | 166 | 得意、释压、豪迈、嘲弄或失控 |
| 微笑 | 112 | 克制、礼貌、洞察或含情 |
| 冷笑 | 97 | 敌意、拒绝或权力施压，通常不是喜剧 |
| 好笑 | 61 | 明确的滑稽判断 |
| 哈哈 | 204 | 口头表演、豪放反应或声场占领 |
| 嘻嘻 | 27 | 游戏、顽皮或不肯正面回答 |
| 玩笑 | 18 | 文本明确标注的戏弄行为 |
| 滑稽 | 11 | 直接评价外部形态或局面 |
| 正色 | 16 | 明确标记转入认真状态 |
| 肃然 | 5 | 庄严或价值判断突然上升 |

这组差异说明：作品很少依靠“某人说了一个笑话”来制造诙谐，更多让笑从对白攻防、身份反差和动作后果中自行出现。“正色、肃然”又远少于笑的标记，说明换挡通常不靠旁白命名，而靠称谓、语速、现实后果和人物任务改变。

其他外部动作信号包括：

- 拍手约38次、格格约36次、伸舌约21次：年轻人物常把诙谐身体化；
- 故意约30次、假装约27次、戏弄约17次：诙谐经常是一项有目的的策略；
- 一本正经约6次：严肃表面与荒唐内容的反差虽不高频，却很醒目；
- 又惊又喜约46次、破涕为笑约3次、又哭又笑约2次：复合情绪比整齐单调的情绪切换更常见。

跨字窗粗检中，笑后不远处进入正色、叹息、愤怒、突发声响或反预期的情况很多；悲、泪、哭与笑也反复出现在同一局部场景。这些数字只说明语气交错是稳定现象，不是要求AI按次数配额。

从代表性场景可归纳出：

- 机敏人物的诙谐常用于夺取话语框架、试探、拖延或激怒，不只是显示可爱；
- 豪侠人物以食欲、自嘲和市井口吻卸下宗师架子，但遇到是非会立刻恢复朴素判断；
- 游戏型人物可以在讲述惨事时岔开、猜谜、催问，诙谐没有取消悲痛，反而显出他的独特哀悼方式；
- 质朴人物常因认真回答隐含玩笑而产生错位，但他的真诚不能被写成持续受辱；
- 极度滑稽的动作可以逐渐转成寒意与悲悯，旁观者的反应和环境余声负责重新定调；
- 轻松段落仍在传武、结盟、探话、求医和验证关系，从不只是暂停主线。

## 三、笑声不等于诙谐

“笑”首先是一种外部行为，其意义由关系和目的决定。

| 笑的类型 | 潜在功能 | 是否一定诙谐 |
|---|---|---|
| 亲近之笑 | 接纳、恢复关系、允许玩笑 | 否 |
| 掩饰之笑 | 藏住害怕、嫉妒、心虚或悲伤 | 否 |
| 权力之笑 | 表示不把威胁当回事 | 否 |
| 讥刺之笑 | 贬低、逼迫、激怒 | 可能产生尖锐诙谐 |
| 自嘲之笑 | 主动降低身份，争取亲近 | 常有诙谐 |
| 释压之笑 | 危险解除后恢复身体 | 常有诙谐 |
| 得意之笑 | 计谋奏效或对手失态 | 视目标与代价而定 |
| 失控之笑 | 创伤、疯狂、绝望或错乱 | 通常不是轻松幽默 |

AI不可把“笑道”当作随机对白标签。写下一个笑之前，必须回答：

```text
谁在笑？
笑给谁看？
想遮住什么？
想让谁失去分寸？
旁观者怎样理解？
笑后局面发生什么变化？
```

同样，诙谐也可以没有任何人发笑。一本正经的错误推断、身份与欲望冲突、重复到第三次的变奏，都可以让读者感到好笑，而场内人物未必知道。

## 四、场景语气的四个坐标

不要只给场景贴“轻松／严肃”二元标签。至少记录四个坐标：

```yaml
tone:
  pressure: low | medium | high       # 现实危险和失败代价
  relational_warmth: cold | mixed | warm
  openness: guarded | testing | open # 人物是否愿意暴露自己
  dignity_level: ordinary | formal | ceremonial
```

同样是诙谐，可以处在不同位置：

| 类型 | 压力 | 关系温度 | 主要用途 |
|---|---|---|---|
| 日常玩闹 | 低 | 暖 | 建立亲密、展示习惯 |
| 陌生试探 | 中 | 混合 | 探底、争夺定义权 |
| 临敌机锋 | 高 | 冷 | 扰乱判断、拖延、激怒 |
| 苦中作乐 | 高 | 暖 | 共同承压、保持行动能力 |
| 黑色荒诞 | 高 | 冷或混合 | 暴露代价、制造寒意 |
| 宗师自嘲 | 低或中 | 暖 | 降低身份距离、保存权威弹性 |

所以“有笑声”不等于压力降低，“没有笑声”也不等于场景庄严。

## 五、诙谐的最小结构

一个可工作的诙谐节拍通常包含六个位置：

```text
1. 共同事实：在场者都能接触的现实
2. 默认预期：按身份、礼法或常理，本应怎样
3. 偏离者：某人物按自己的特殊逻辑处理
4. 迟半拍识别：另一人物或读者稍后发现错位
5. 回击或后果：动作、短答、沉默或关系变化
6. 退出：回到任务，或让笑点引出下一压力
```

原创示例：

```text
共同事实：守门人要求报上师承。
默认预期：来客应恭敬自报门派。
偏离：来客认真报出教自己做饭的婶娘姓名。
识别：守门人以为受辱，同行者却知道来客确在如实回答。
后果：守门人发怒出手，反而暴露守门阵法的缺口。
退出：众人立刻利用缺口入门。
```

真正有效的是“如实回答＋框架不同＋行动后果”，不是单独编一句俏皮话。

## 六、十二种诙谐机制

### 1. 字面与言外错位

一方按社交暗示说话，另一方按字面事实回答：

```text
暗示、客套或反话
→ 质朴者认真处理字面
→ 暗示者的框架失效
```

适合表现真诚、文化差异和初识关系。不能让质朴人物永远听不懂；他应能积累经验，并在擅长领域反过来占优。

### 2. 重新定义问题

机敏人物不回答对方的问题，而改写其中一个词、称谓或前提：

```text
对方设定A
→ 复现A中的关键词
→ 赋予第二种含义
→ 迫使对方在新框架中回应
```

这类诙谐同时完成套话、拒答、激怒或争取旁观者。见 `character-voice.md` 的说话策略。

### 3. 知识不对称

读者或部分人物知道真相，另一个人却以错误前提郑重行事。

```text
真实信息由甲和读者持有
→ 乙认真执行错误方案
→ 甲有意维持或轻推误会
→ 新细节使错位扩大
```

必须遵守公平信息边界，不能让乙忽略显而易见的事实。完整方法见 `information-control.md`。

### 4. 身份与欲望反差

高身份人物在一个极日常欲望面前失去仪态，或不起眼人物在大是大非前突然显出权威：

```text
公开身份要求克制
＋私人欲望十分具体
→ 身份语言与身体行动互相拆台
```

食欲、怕麻烦、爱玩、爱面子都可使用。欲望应使人物更完整，不能把人物降成单一丑角。

### 5. 自我暴露

人物想掩饰欲望，却因解释过多、动作太快或否认太急而暴露：

```text
“我并不在意”
＋手已经伸过去
＝语言与行动的反差
```

这是温和而耐用的诙谐，尤其适合师徒、恋人和老友。

### 6. 重复后变奏

相同问答或动作出现两至三次，最后一次改变关键词、对象或结果：

```text
第一次建立规则
第二次让人预期复现
第三次保留骨架，改变落点
```

笑来自读者提前预测又被小幅偏转。原样重复只会拖沓。

### 7. 一本正经地荒唐

人物以完整因果、正式礼数或学术口吻处理一个明显失衡的命题。

关键是人物自己相信这套逻辑，或有明确策略需要装得相信。叙述者不要先说“他说得十分滑稽”，让结构自行显形。

### 8. 身体与空间后果

语言游戏最终落到可见空间变化：坐错位置、进退受阻、身份互换、物件落到不该在的人手里。

```text
人物计划
→ 空间或物件不配合
→ 身体被迫暴露真正处境
```

身体喜剧必须写清方向、受力和结果。不能把残疾、肥瘦、年老、性别或族群身份本身当笑点。

### 9. 身份倒置与角色互换

命令者被迫执行自己的命令，考问者反被考住，师父被徒弟拿住软肋，追捕者反成引路者。

倒置最好来自既有规则或人物选择，而不是作者任意羞辱。完成后应改变权力、亲密或行动许可。

### 10. 第三者三角

甲乙的暗线由丙误读、点破或故意装傻：

```text
甲隐藏
乙知道
丙说破一个边缘事实
→ 甲乙同时以不同方式反应
```

旁观者既是笑声的见证人，也能改变场面中的面子成本。三角关系比一人连续抖机灵更有戏。

### 11. 称谓、外号与回环

称谓可被抬高、降格、误用、夺用或恢复。第一次产生玩笑，后文在关系改变后复现，便可转成亲情、羞愧或怀念。

外号不能只靠丑化外貌。更有效的是压缩人物自我形象与江湖评价之间的差异。

### 12. 面具式诙谐

人物用玩笑挡住恐惧、歉意、眷恋或悲痛：

```text
真正情绪将要暴露
→ 人物切入熟悉的玩笑方式
→ 对方听出玩笑不够自然
→ 决定点破、配合或沉默
```

这类诙谐必须留下裂缝，否则读者只看见轻浮。情感显影方法见 `emotional-subtext.md`。

## 七、人物专属诙谐系统

不是每个人都要会说俏皮话。人物可以承担不同的诙谐角色：

| 角色 | 主要机制 | 不能写成 |
|---|---|---|
| 框架改写者 | 双关、反问、故意误解 | 永远正确的段子机器 |
| 字面直答者 | 认真处理隐含玩笑 | 没有尊严的傻瓜 |
| 欲望泄漏者 | 身份与食欲、虚荣、怕事冲突 | 只有一个欲望的丑角 |
| 游戏化者 | 把危险、规则和胜负变成游戏 | 对后果毫无感受的人 |
| 冷面裁断者 | 长铺之后一句现实判断 | 人人通用的吐槽者 |
| 自嘲权威者 | 主动降格以拉近关系 | 权威完全失效 |
| 被迫见证者 | 反应、沉默、误读 | 只负责捧哏的工具人 |
| 伪装者 | 用笑隐藏目的或情绪 | 每次都露出破绽的反派 |

为主要人物维护：

```yaml
humor_system:
  comic_engine:                # 字面、框架、欲望、身份、身体、知识差等
  default_role:                # 发起者、直答者、见证者、冷面裁断者等
  uses_humor_to: []            # 亲近、试探、拖延、掩饰、夺权、释压
  safe_targets: []             # 可调侃的对象与议题
  forbidden_targets: []        # 绝不会拿来玩笑的创伤、身份或价值
  preferred_form:              # 短答、反问、故事、动作、外号、一本正经
  laughter_style:
  response_when_teased:
  overplays_when:
  seriousness_trigger:         # 哪类事实一出现便停止玩笑
  recovery_after_seriousness:  # 怎样重新允许轻松进入
```

同一人物也会随对象变调：

- 对亲近者，玩笑可以确认安全和共同记忆；
- 对陌生人，玩笑常是试探与划界；
- 对上位者，玩笑可能是冒犯、讨好或绕过正式权力；
- 对敌人，玩笑常是心理攻击，不代表场景轻松；
- 对伤者与弱者，玩笑需要获得关系许可，否则容易成为残酷。

## 八、关系、权力与伦理边界

判断一个笑点能否成立，先画方向：

```text
谁拥有现场权力？
谁承担笑点代价？
被笑者能否回击、拒绝或退出？
玩笑是否利用真实创伤？
笑后关系更近、更远，还是权力更不平等？
```

优先使用：

- 向上调侃权威和虚伪规则；
- 熟人之间有回击能力的横向玩笑；
- 人物自嘲自己的欲望与失态；
- 对手因傲慢、贪心或错误选择自陷困境；
- 空间、物件和信息造成的情境错位。

谨慎或避免：

- 把身体特征、残疾、贫穷、口音、年龄、性别或族群本身当笑点；
- 把性骚扰、羞辱或真实伤害写成无代价的轻松桥段；
- 强者持续戏弄无力反击者，却要求读者把强者视作可爱；
- 受害者刚遭遇损失，旁人立即用玩笑替他“治愈”；
- 以“他是坏人”为由，把任意残酷行为包装成喜剧。

参考旧作品时，应保留“身份倒置、规则回击、行动报应”的机制，主动剥离依赖身体羞辱和时代偏见的笑料。

## 九、情绪换挡的六步结构

一处自然换挡包含：

```text
1. 基准：先让当前主调稳定两三个节拍
2. 异调：新情绪先以小信号进入
3. 铰链：一个具体事实、称谓、物件、伤势或声音触发转向
4. 变速：句长、话轮、动作幅度和叙述距离随之改变
5. 接管：人物作出属于新情绪的行动
6. 余味：保留旧主调的一处痕迹
```

原创示例：

```text
基准：三人争论谁做的汤最难喝，话轮短而快。
异调：老人端碗时忽然少说了一句惯常的骂词。
铰链：碗底露出故友留下的烧痕。
变速：众人停止抢话，老人把碗慢慢转了半圈。
接管：他决定改变路线，去赴多年前失约的一场祭奠。
余味：临走仍嫌汤淡，却亲手把空碗洗净。
```

换挡铰链必须在现场可感知。常用铰链：

- 某个禁忌称谓被说出；
- 玩笑误触真实伤口；
- 身体疼痛或危险重新出现；
- 一名新人物进入；
- 应有回应没有出现；
- 物件显露真实来源；
- 身份职责被重新唤起；
- 计谋产生超出预期的伤害；
- 外部声音宣告下一事件到来。

## 十、八种常用换挡方向

### 1. 危险 → 释压诙谐

危险必须先得到局部控制，再允许身体和日常欲望回来：

```text
脱险或暂时停战
→ 检查伤势与人数
→ 一个不合英雄气概的现实需要出现
→ 人物按各自性格回应
→ 笑后提出下一目标
```

不要在伤亡尚未被承认时抢先搞笑。释压不是遗忘代价。

### 2. 诙谐 → 新危险

让玩笑本身暴露位置、激怒对手、耽误时机或误碰机关：

```text
游戏规则建立
→ 人物得意或分心
→ 笑点产生物理后果
→ 声音、攻击或异常静默进入
→ 立即返回行动语法
```

新危险不能完全无关，否则像作者粗暴掐断笑声。

### 3. 诙谐 → 温情

最可靠的信号是机锋减少，语言突然变简单：

```text
互相调侃
→ 某人无意暴露真正珍视之物
→ 另一人不再乘胜追击
→ 用小动作接住
→ 保留一句轻微玩笑收尾
```

温情来自“知道何时不再开玩笑”。

### 4. 温情或悲痛 → 轻微诙谐

先让情感落地，再由人物自身的习惯恢复一点日常：

```text
真情已被承认
→ 必须继续生活或完成任务
→ 人物用熟悉的小毛病、自嘲或现实问题重新开口
→ 对方允许这一转向
```

笑不是消除悲痛，而是证明关系仍能承载悲痛。

### 5. 诙谐 → 道德庄严

让人物的底线或公共身份被触发：

```text
市井玩笑或身份降格
→ 出现欺弱、失信、背叛或公共危险
→ 玩笑词汇停止
→ 称谓、句长和判断变朴素
→ 人物承担责任
```

庄严不靠华丽宣言，往往靠一句不再绕弯的决定。

### 6. 庄严或解释 → 日常落地

长篇掌故、武学原理或价值讨论后，用具体身体需求、物件或关系问答返回现场：

```text
抽象层升高
→ 结论完成
→ 人物口渴、肚饿、走错路或被旁人打断
→ 短动作恢复地面
```

日常落地应保存刚才结论的影响，不把严肃内容嘲成无意义。

### 7. 诙谐 → 悲悯或寒意

滑稽行为逐步显露真实代价：

```text
外形或逻辑可笑
→ 重复加深
→ 旁观者发现此人已失去控制、身份或所爱
→ 笑声停止
→ 环境余声、远去动作或沉默收尾
```

这种换挡适合疯狂、衰败和胜利后的空虚。不要继续追加包袱。

### 8. 悲痛 → 人物特有的荒诞继续

有些人物不会停留在标准哀恸中，而会被未完成的故事、游戏或职责重新吸走：

```text
悲痛真实爆发
→ 人物忽然想起自己的惯常任务
→ 以看似不合时宜的方式继续
→ 一个细节证明悲痛仍在
```

这不是情绪不连贯，而是人格连续。关键在于保留哭痕、停顿、称谓或后续选择。

## 十一、语言与节奏信号

### 诙谐状态

- 话轮较短，抢答、复现和故意答非所问增加；
- 对方刚说过的关键词被拿来变义；
- 长句铺设规则，短句改写规则；
- 动作回应多于解释性心理；
- 旁观者的一怔、忍笑、误解或沉默构成迟半拍；
- 句尾落在具体物件、身体位置或出乎意料的结果。

### 转入严肃

- 笑声或口头禅停止；
- 称谓恢复正式，或突然变得极亲；
- 句子由跳跃转为短而完整；
- 问答减少，陈述和命令增加；
- 叙述距离短暂推近身体或判断；
- 动作幅度缩小，出现停住、放下、收回；
- 环境中原被忽略的声音重新进入。

### 转入轻松

- 身体从冻结恢复到饮食、整理、赶路等日常动作；
- 正式称谓被亲昵称谓或外号替换；
- 一人允许另一人重新调侃；
- 长解释由一个现实短问截断；
- 紧绷的同一动作第一次出现无害变奏。

不要一次使用所有信号。一次换挡选择两至三项便足够。

## 十二、场景和长篇的张弛组织

### 场景内部

为每场记录：

```yaml
tone_arc:
  opening_tone:
  pressure_level:
  counter_tone:
  hinge:
  new_dominant_tone:
  residue:
  consequence:
```

一场戏通常只需要一次主要换挡，高潮场景可有两次，但每次都必须改变行动或关系。

### 章节之间

相邻章节不要只在“更危险”上升级。可以轮换：

```text
外部危险
→ 关系玩闹与训练
→ 信息调查
→ 文化或旧事
→ 情感靠近
→ 公共冲突
```

轻松章节仍要埋入：

- 新能力；
- 新称谓或关系许可；
- 小物件；
- 错误判断；
- 下一危险的微弱信号。

### 长篇检查

- 连续三个高压场景后，读者是否仍有分辨强弱的感受力？
- 连续两个轻松场景是否都在推进不同内容？
- 每次严肃都由人物底线触发，还是作者统一升调？
- 笑点是否随着关系发展而变义？
- 早期共同玩笑能否在离别、背叛或重逢时成为回声？

张弛不是固定的“一紧一松”，而是不断改变压力、关系温度、开放度和庄严程度。

## 十三、AI生成流程

### 第一步：确定现实任务

先写清人物正在救人、求路、试探、练功、谈判、逃亡还是吃饭。没有任务的诙谐容易变成小品。

### 第二步：标定当前语气坐标

记录压力、关系温度、开放度与庄严程度。明确现在是否允许玩笑，以及谁有权开。

### 第三步：选择人物诙谐机制

从人物卡读取其字面、框架、欲望、身份、身体、知识差或自嘲机制。不要先编“金句”。

### 第四步：安排角色与目标

决定：

- 谁发起；
- 谁按另一套框架理解；
- 谁旁观；
- 笑点真正指向哪种选择、规则或虚荣；
- 谁承担代价，是否能回击。

### 第五步：让笑点产生后果

至少改变一项：

```text
信息｜权力｜关系许可｜行动路线｜物件归属｜危险程度
```

### 第六步：设计换挡铰链

若场景需要转调，选择一个已在现场的称谓、物件、伤势、声音、职责或后果作为铰链。不要空投新事故。

### 第七步：改变表达系统

随新主调改变句长、话轮、动作幅度、称谓和叙述距离。只写“他忽然严肃起来”不算完成换挡。

### 第八步：保留余味并退出

用一个仍带旧情绪的动作或短句收束，然后回到主线任务。不要解释读者为什么应该笑或感动。

## 十四、场景模板

### 模板A：字面直答

```text
甲用客套或暗示提出要求
→ 乙按字面认真回答
→ 甲以为乙故意讥刺
→ 丙知道乙确实诚实
→ 误会迫使甲暴露真正目的
```

### 模板B：权威的日常软肋

```text
权威人物保持正式身份
→ 具体欲望进入
→ 嘴上拒绝，身体先行动
→ 晚辈不点破，只顺势提出条件
→ 权威接受条件但重申底线
```

### 模板C：临敌机锋

```text
对手用身份或规则压人
→ 主角复现关键词并重新定义
→ 对手被迫解释
→ 旁观者判断改变
→ 主角利用迟疑完成实际行动
```

### 模板D：笑中入情

```text
双方沿共同玩笑来回两轮
→ 一句话无意碰到真实缺席或损失
→ 发起者停止追击
→ 用物件或照料动作接住
→ 以较轻的旧称谓收束
```

### 模板E：笑转危险

```text
人物因计谋成功而放松
→ 玩笑动作制造声响或暴露位置
→ 应有笑声处突然无人回应
→ 外部威胁进入
→ 短动作夺回节奏
```

### 模板F：荒诞转寒意

```text
某人重复滑稽而失控的动作
→ 旁观者先笑
→ 一个称谓、伤口或错误认人暴露代价
→ 无人再笑
→ 人物远去，余声仍在
```

### 模板G：庄严落回日常

```text
人物作出价值裁决
→ 众人沉默接受
→ 一个现实小问题要求立即处理
→ 人物恢复自己的日常声口
→ 价值裁决仍改变接下来的行动
```

## 十五、改写与诊断

### 把插科打诨改成情境诙谐

原始写法：

> 两人正在逃命，他忽然讲了个笑话，大家都笑了起来，气氛轻松不少。

改写步骤：

1. 保留逃命中的具体问题；
2. 让人物以自己的知识或欲望错误处理它；
3. 让同行者按另一套框架回应；
4. 让诙谐帮助或妨碍逃亡；
5. 让现实危险决定何时停止。

原创示例：

> 两人伏在粮车底下，车轮每过一道石缝，他便伸手去护怀里的烧饼。师妹忍了两回，低声道：“你再护它，待会儿追兵不杀你，我先杀。”他想了想，把烧饼掰成两半，塞给她一块。她没再骂，接过来咬了一口，抬手示意前方有人。

这里的笑意来自欲望泄漏，也完成分食、关系缓和和危险提示。

### 八问诊断

1. 场景删去笑点后，是否仍完全一样？
2. 诙谐是否来自这个人物稳定的欲望、盲点或策略？
3. 谁持有默认框架，谁使它偏离？
4. 笑点指向行为与规则，还是指向不可选择的身份特征？
5. 被调侃者是否拥有回击、拒绝或退出能力？
6. 转调是否有现场可感知的具体铰链？
7. 新主调是否通过句法和行动建立，而非只靠情绪标签？
8. 旧情绪是否留下一处余味，并影响后续行动？

### 删除测试

删除“笑、好笑、滑稽、幽默、诙谐”等直接标签。如果剩余文本仍能看出：

- 默认预期是什么；
- 哪个人按另一套逻辑行动；
- 其他人何时识别错位；
- 这次错位改变了什么；

说明诙谐结构已经成立。

### 换挡回看测试

只看铰链前后各三句：

- 前一种主调是否已经建立？
- 铰链是否属于现场，而非作者强行插入？
- 句长、称谓、动作或话轮是否至少有一项改变？
- 后一种情绪是否接管行动？
- 若删去“忽然严肃、转悲为喜”等标签，转向是否仍可感知？

## 十六、常见失败

### 1. 段子空投

人物停下任务讲一个可搬到任何小说里的笑话。修正：让诙谐从当前物件、规则、知识差和关系中发生。

### 2. 人人机锋

所有人物都能立即反转关键词、妙语连珠。修正：分配框架改写者、字面直答者、冷面裁断者和见证者等不同角色。

### 3. 笑道随机化

对白标签轮流使用“笑道、微笑道、哈哈道”，却没有笑的对象和目的。修正：标出笑给谁看以及它改变什么。

### 4. 老实等于供人取笑

质朴人物反复听不懂，且从不成长。修正：让其真诚也能拆穿复杂人的虚假，并在事实、承诺或行动上占优。

### 5. 聪明等于脱口秀演员

机敏人物每句都漂亮，却不探话、不设局、不承担后果。修正：一句机锋必须是一项策略动作。

### 6. 欲望成为单一标签

贪吃者永远只说吃，爱玩者不知生死。修正：让日常欲望与责任、判断和感情形成反差，并设置明确的严肃触发点。

### 7. 霸凌包装成幽默

强者羞辱弱者，作品只安排旁人喝彩。修正：改变笑点方向，给被笑者回击能力，或明确展示关系与道德代价。

### 8. 身份特征直接当笑点

以肥瘦、残疾、衰老、贫穷、性别或口音代替诙谐结构。修正：把笑点移到自负、规则冲突、欲望泄漏和行动反噬。

### 9. 危险中强行嘴贫

人物在无暇说话时持续完整抖机灵。修正：高压诙谐缩成短答、动作、误会或一处现实反差，并服从呼吸和任务。

### 10. 喜剧复位键

刚发生死亡或背叛，下一句玩笑令所有人恢复如常。修正：先承认代价；笑可以恢复行动能力，不能抹掉后果。

### 11. 宣布换挡

只写“气氛顿时严肃起来”。修正：让称谓、句长、身体、话轮和行动发生可见变化。

### 12. 铰链空投

作者用无关袭击打断轻松，或用无关笑话打断悲痛。修正：让转向由已在场的物件、关系、伤势、职责或此前伏笔触发。

### 13. 新情绪抹除旧情绪

人物一笑便不再悲伤，一正色便毫无亲近。修正：保留一处余味，让两种情绪短暂共存。

### 14. 轻松段不推进

整段可从小说删去，主线毫无变化。修正：轻松场景至少完成关系许可、能力训练、信息交换、物件植入或下一危险预示之一。

### 15. 全书机械一紧一松

每次大战后固定吃饭说笑，形成可预测节拍。修正：在压力、关系温度、开放度与庄严程度四轴上变化，不只切换快乐和悲伤。

## 十七、可直接交给AI的指令

```text
设计诙谐和情绪换挡时，不插入可脱离场景的段子，也不把“笑道”当作幽默本身。

1. 先写清当前现实任务、失败代价以及人物关系；诙谐必须在任务进行中发生。
2. 为人物选择专属诙谐机制：字面直答、框架改写、知识错位、身份与欲望反差、自嘲、重复变奏、身体后果或面具式玩笑。
3. 明确谁建立默认预期、谁使它偏离、谁迟半拍识别，以及谁承担笑点代价。
4. 笑点优先指向人物的选择、自负、虚伪规则和行动反噬；避免把身体、残疾、贫穷、年龄、性别、族群或真实创伤本身当笑点。
5. 每个诙谐节拍至少改变信息、权力、关系许可、行动路线、物件归属或危险程度中的一项。
6. 需要转调时，先让当前主调成立，再用现场已有的称谓、物件、伤势、声音、职责或行动后果作为铰链。
7. 换挡后同步改变句长、话轮、称谓、动作幅度或叙述距离；不要只写“忽然严肃起来”。
8. 新情绪接管行动，但保留旧情绪的一处余味。笑不能抹掉悲痛，庄严也不必消灭亲近。
9. 高压场景中的诙谐必须短促并服从现实呼吸；低压场景仍须推进关系、能力、信息、物件或后续风险。
10. 写完删除“好笑、滑稽、气氛轻松、转悲为喜”等标签，检查错位和换挡是否仍能从行动与语言中成立。
```
