# 金庸写作风格卡·宏观叙事总原则

本模块由 `SKILL.md` 按任务类型加载；长篇秘密、误判链、线索变义和读者认知管理见 `information-control.md`，张弛、诙谐与具体换挡铰链见 `humor-and-tonal-shifts.md`。

## 一、核心公式

```text
稳定而鲜明的人物天性
→ 在不同利益面前反复接受验证
→ 被多项彼此冲突的义务逼迫
→ 在有限信息下作出选择
→ 选择产生真实而不可轻易撤销的后果
```

情节不是外加在人物身上的热闹事件，而是人物性格在压力下不断显形的过程。

## 二、九项总原则

### 1. 人物通过反复选择被证明

不要只介绍人物“忠厚、聪明、刚烈、贪恋富贵”。让同一核心性格在不同场景中反复产生：

- 能力；
- 魅力；
- 盲点；
- 代价。

人物卡应写成：

```yaml
core_trait:
helps_when:
hurts_when:
temptation:
repeated_choice:
breaking_point:
```

人物的优点必须也能制造困难，否则只是奖励属性。

### 2. 真正的发动机是义务冲突

强情节不只来自“敌人很强”，更来自两个不能同时放弃的责任：

- 师恩与爱情；
- 血缘与养育；
- 私人承诺与公共立场；
- 报仇与证据；
- 江湖规矩与现实是非；
- 兄弟情义与国家责任。

设计方式：

```text
义务A有真实来源
义务B也有真实来源
→ 两者不能同时完成
→ 任何选择都付出代价
```

不要把其中一项偷偷写成明显错误，否则只是普通选边。

### 3. 误导依靠真证据与错解释

高质量误会的结构：

```text
证据都是真的
＋人物视角有限
＋情绪或偏见影响解释
＝合乎情理的错误结论
```

揭谜时不新增万能证据，而让旧线索获得第二种解释。

AI必须记录：

| 线索 | 客观事实 | 人物解释 | 错误原因 | 后续重释 |
|---|---|---|---|---|

### 4. 场景是一台压力机器

有效场景不只是地点，还应包含：

```text
空间限制
＋身体限制
＋行动目标
＋信息差
＋多方人物陆续进入
＋失败后果
```

例如密室、船舱、孤岛、悬崖、酒楼和阵法，都因限制人物行动而产生戏剧性。

场景规划卡：

```yaml
space:
who_can_enter:
who_cannot_move_or_speak:
who_knows_what:
immediate_goal:
failure_cost:
new_arrival:
```

### 5. 每场戏至少推进两条线

一场戏应同时推进下列至少两项：

- 外部事件；
- 人物关系；
- 身份信息；
- 谜团线索；
- 能力变化；
- 道德选择；
- 后续约定。

若场景只完成一项单纯说明，应与其他场景合并。

### 6. 对白和武打都是行动

对白用于试探、欺骗、拖延、激怒、结盟和裁决；武打用于救人、夺物、脱身、验证身份和迫使选择。

武打的基本结构：

```text
目标
→ 试探
→ 识破
→ 变招
→ 地形或第三方干扰
→ 局势改变
```

招式名只是地标，不是情节本身。

### 7. 情感通过行动与选择显露

少直接重复“爱、恨、悲伤、感动”。优先通过：

- 危急时先救谁；
- 是否守约；
- 是否替对方承担；
- 对遗物和称谓的变化；
- 欲言又止；
- 小动作和事后余味。

情感高潮应落到选择，而不只落到表白。

### 8. 节奏依靠不断换味

长篇常见循环：

```text
危险
→ 诙谐缓冲
→ 人物关系生长
→ 江湖或文化掌故
→ 新线索
→ 更大危险
```

轻松段不是填充，而是：

- 让人物建立感情；
- 恢复读者感受力；
- 为下一次危机制造反差；
- 暗中埋设物件和信息。

### 9. 历史必须进入私人命运

史实不能只作背景板。公共事件应逐步压到人物身上：

```text
时代局势
→ 家庭创伤或人物命名
→ 阵营与承诺
→ 私人关系发生冲突
→ 人物必须选择
```

宏大主题只有成为人物失去什么、背叛什么或守住什么时，才真正进入故事。

## 三、长篇推进的三层发动机

### 外层：行动任务

寻找、救援、复仇、赴约、护送、夺物、逃亡、比武。

### 中层：关系与信息

误会、身份、婚约、师门、旧怨、秘密、线索。

### 内层：价值冲突

人物究竟愿意为什么付出代价。

每个重要篇章都应同时拥有三层。只有外层会显得热闹而空；只有内层会显得议论而不动。

## 四、人物成长的写法

成长不是更换核心性格，而是让核心性格获得更大的认识范围。

```text
早期：性格凭本能发挥
中期：性格不断造成成功与损失
后期：人物理解性格的代价
终局：仍保持本性，但作出更成熟的选择
```

例如“诚”不必变成“机巧”，而可以从对一个人守信，成长为理解多个承诺的层级与边界。

## 五、章节推进模板

```text
1. 承接上一回未解状态
2. 给人物一个眼前目标
3. 加入空间、身体或信息限制
4. 让新人物或新线索进入
5. 旧判断受到挑战
6. 人物依据本性作出选择
7. 局面暂时完成或反转
8. 以新危险、未解身份或道德难题收束
```

章节不必每次完整使用八步，但“选择改变局面”不可缺少。

## 六、可直接交给AI的宏观指令

```text
规划故事时，以人物选择而非事件数量为核心。

1. 为每个主要人物定义一个稳定核心性格，并说明它带来的能力、魅力、盲点和代价。
2. 给主角安排两项都具有正当来源、却无法同时履行的义务。
3. 重要误会必须建立在真实线索上；错误来自有限视角和人物偏见。
4. 每个高潮场景设置空间限制、身体限制、信息差、失败后果和至少一名新入场者。
5. 每场戏至少推进事件、关系、谜团、能力、选择中的两项。
6. 对白和武打都必须改变局势，不罗列空洞谈话或招式。
7. 让情感通过照料、让步、守约、误会和牺牲显露，少作抽象总结。
8. 在危险、诙谐、亲近、掌故和新线索之间换味。
9. 历史和世界局势最终必须成为人物私人关系中的现实难题。
10. 章节结尾留下迫近危险、未解信息、关系裂缝或两难选择。
```

## 七、场景审核清单

- 当前场景是谁想得到什么？
- 谁或什么阻止他？
- 空间和身体有什么限制？
- 每个人知道的内容是否不同？
- 人物依据哪一项核心性格行动？
- 这个优点是否同时造成代价？
- 场景推进了哪两条以上的线？
- 对白与武打是否改变了权力和信息？
- 结果是否影响后续，而非下一场自动复原？
- 场景结尾留下什么新的不稳定状态？

## 八、常见失败

- 用性格标签代替反复选择；
- 冲突只有好人与坏人的简单对立；
- 靠伪造证据或作者隐瞒制造误会；
- 场景没有限制，人物随时可以离开或求援；
- 一场戏只传递背景信息；
- 武打结束后人物关系和局势毫无变化；
- 爱恨全靠人物直接说出；
- 历史说明与人物命运彼此分离；
- 每章只追求更强敌人，没有更难选择；
- 结尾只用突然袭击，不建立长期承诺和回收。
