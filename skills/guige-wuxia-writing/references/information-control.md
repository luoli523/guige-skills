## 一、核心结论

信息差不是“作者知道但故意不告诉读者”，而是同一事实进入不同人物时形成不同版本：

```text
客观事实
→ 人物从有限位置获得证据
→ 证据经过经验、愿望、恐惧和利益解释
→ 形成暂时信念
→ 人物按信念行动
→ 行动产生新证据或代价
→ 旧信念被确认、修正或推翻
```

同时还要维护读者的位置：

```text
世界真实发生了什么
≠ 人物实际看见什么
≠ 人物认为发生了什么
≠ 人物愿意对外说什么
≠ 读者目前相信什么
```

优秀误导不伪造事实，而是让真实证据支持一个合理但不完整的解释。揭示时，读者应能回想：“原来先前那些细节是这个意思。”

## 二、全书语料观察

对全文进行字符串粗检，可以看到认知的不确定性远多于简单确认：

|---|---:|---|

| 知道 | 573 | 确认知识持有人或新获信息 |
| 心想 | 617 | 形成即时解释和行动计划 |
| 心道 | 175 | 保留人物自己的判断声口 |
| 似乎 | 157 | 暂不确认表象 |
| 只道 | 113 | 人物把有限解释当成事实 |
| 以为 | 76 | 明确标记可被后文修正的信念 |
| 多半 | 58 | 带概率的推断 |
| 料想 | 51 | 根据经验预判 |
| 原来 | 432 | 在异常之后补足机关或事实 |
| 哪知 | 240 | 修正人物或读者的预期 |
| 岂知 | 85 | 加强反预期 |
| 其实 | 71 | 校正表面理解或人物自欺 |
| 不料 | 57 | 让外部世界打断计划 |
| 果然 | 150 | 用结果确认此前推断 |

跨句粗检还发现，“心想”后不远处接“哪知、岂知、不料”的结构约有50处；“只道”后接校正约20处。这说明心理判断常被当作可检验的临时模型，而非作者确认。

其他相关信号包括：

- 小孔约29处、躲在约57处、藏在约24处：空间位置直接决定谁能看见或听见；
- 假装约27处、改扮与乔装合计约9处：身份表象成为可操作信息；
- 偷听、窃听合计约12处：信息获取本身常带风险；
- 灭口约4处、无对证约3处：信息持有人和证据保存会直接影响行动。

这些数字只是电子文本的字面趋势，不作为创作配额。

## 三、四张信息平面

### 1. 客观事实平面

记录世界中实际发生的事情，不随人物观点改变：

- 谁做了什么；
- 时间与地点；
- 物件真实来源；
- 身份和关系；
- 因果链；
- 哪些证据被制造、移动或破坏。

这张平面是作者后台真相，不等于正文应立刻公开。

### 2. 人物认知平面

每个人分别记录：

```text
亲知｜听闻｜推断｜误信｜怀疑｜隐瞒｜不知道自己不知道
```

同一人物也可能同时持有互相冲突的解释，只是置信度不同。

### 3. 公开叙事平面

记录人物实际说出、写下、展示或伪造的版本。它受目的控制：

- 完整真话；
- 部分真话；
- 真证据配假解释；
- 假证据配真结论；
- 有意识撒谎；
- 因误判而真诚地说错；
- 沉默或转移话题。

不要把“人物说过”自动当作“作品确认”。

### 4. 读者认知平面

记录读者目前：

- 已被叙述确认的事实；
- 只从人物处听来的说法；
- 能看到但人物未注意的证据；
- 被引导形成的主假设；
- 应保留的备选解释；
- 下一次期待回答的问题。

读者不需要知道后台真相，但必须拥有足够证据理解人物为何行动。

## 四、认知形成链

一个有效认知节拍包含：

```text
1. 证据进入感官
2. 人物选择注意其中一部分
3. 从记忆中调用相关经验
4. 形成带置信度的解释
5. 决定是否公开
6. 按此解释行动
7. 从结果中获得反馈
```

AI常见错误是跳过前四步，直接写“他立刻明白了一切”。除非证据具有唯一解释，否则必须展示至少一小段连接过程。

### 原创微型示例

```text
事实：信是徒弟伪造的。
证据：纸张来自师门，印泥却是县衙常用颜色。
注意：掌门先认出纸，没有留意印泥。
经验：他相信只有本门弟子能得到这种纸。
解释：外敌偷入门中写信嫁祸。
行动：封山搜敌，反而把真正伪造者留在山内。
反馈：第二封信出现时，封山已证明外敌不可能进出。
```

误判不是人物变笨，而是人物把一条强证据看得太重。

## 五、信息来源与可信等级

### 1. 直接经历

人物亲自做过或承受过。可信度最高，但记忆、视角死角和情绪仍会扭曲解释。

### 2. 亲眼亲耳

人物在场看见或听见。必须记录：距离、光线、遮挡、语言能力、是否看完整过程。

### 3. 实物与痕迹

伤口、字迹、气味、器物、足迹、缺口、账册。实物通常真实，但来源和意义可以被误读或栽赃。

### 4. 可信人物转述

说话者诚实不等于内容正确；他也可能只看见一部分。

### 5. 敌对或利害相关者转述

需要拆成：哪些事实可验证、哪些解释服务于他的利益、哪些内容被省略。

### 6. 传闻

只宜建立氛围、偏见和搜索方向，不宜单独完成关键证明。

### 7. 推断

由多条证据形成。必须记录推断者的能力领域；聪明人物也只能在自己熟悉的范围内可靠推断。

### 8. 直觉与预感

适合让人物提高警觉，不宜直接充当真相证明。若预感准确，应能回溯到人物未明确意识到的细节。

## 六、六种读者位置

### 1. 同步发现

```text
读者知识 ≈ 焦点人物知识
```

适合冒险、侦查和第一次进入陌生空间。读者与人物一起获得线索和修正判断。

### 2. 戏剧反讽

```text
读者知道 > 人物知道
```

读者知道危险、身份或谎言，人物仍按错误理解行动。张力来自等待人物何时发现以及代价多大。

### 3. 神秘状态

```text
读者知道 ≈ 人物知道 < 后台真相
```

双方都不知道答案，但应不断获得可解释的新证据。

### 4. 人物领先

```text
人物知道 > 读者知道
```

适合聪明人物设局。正文应让读者看见人物确有计划和准备，只暂缓公开具体方法；不能隐瞒其内心中自然会想到的核心事实。

### 5. 多人物错位

```text
甲知道A｜乙知道B｜丙误信C｜读者同时看见A+B
```

适合误会、联盟、谈判和群像。每次换焦只增加一种必要信息。

### 6. 公开答案、隐藏意义

事件事实已经明白，但人物尚未理解它对身份、关系或价值的真正含义。适合情感揭示和主题回收。

## 七、十二种信息控制机制

### 1. 空间权限

用门、墙、帘、暗室、洞穴、楼层、距离、黑暗和声音传播范围决定谁能感知什么。

```text
位置
→ 可见范围
→ 可听范围
→ 能否行动
→ 信息获得的风险
```

信息差应先有物理原因，再有叙事效果。

### 2. 感官不对称

人物能听见却看不见，能看见动作却听不懂语言，能摸到物件却不知道来源。不同感官提供不同证据等级。

### 3. 身份遮蔽

乔装、化名、旧貌改变、身份地位变化，使“看见此人”不等于“认出此人”。公平识别需要：

- 只有旧关系知道的细节；
- 身体记号或习惯；
- 对共同过去的准确反应；
- 多项证据互相印证。

不要只靠人物突然摘下面具完成全部情感和事实证明。

### 4. 部分真话

最有力的欺骗往往保留可验证事实，只重写动机、因果或遗漏关键一段。

```text
真实事件A
＋真实结果B
－关键因果C
＋有利解释D
＝可信谎言
```

### 5. 真证据、错解释

现场证据全部真实，但被人为摆放、被错误归因，或与人物偏见结合。揭示时不撤销证据，只改变其来源和含义。

### 6. 线索分持

没有任何单一人物拥有完整答案：

- 一人知道时间；
- 一人认得物件；
- 一人见过动作；
- 一人知道动机；
- 一人能解释专业机制。

人物必须合作、交换或互相欺骗，信息才会合拢。

### 7. 证词受身份限制

证人可能诚实，却因年幼、失忆、语言不足、恐惧或社会地位而无法给出完整叙述。聪明询问者应拆小问题，先问可感知事实，后问解释。

### 8. 合理误判

误判公式：

```text
两条以上真实证据
＋一项人物偏见、愿望或知识缺口
→ 最经济的错误解释
```

误判必须推动行动；不能只让人物困惑几页。

### 9. 假确认

错误解释得到第二条表面支持，使人物置信度上升：

```text
初始假设
→ 新证据恰好相符
→ 排除其他解释
→ 人物采取更大代价的行动
```

第二条证据可以真实，只是仍有另一种解释。

### 10. 问题替换

人物以为自己在回答“谁做的”，真正应该问的却是“谁希望别人以为是他做的”。通过改写问题框架打开新推理路径。

### 11. 递进重释

同一线索至少经历两次意义变化：

```text
初见：普通细节
→ 中段：支持错误解释
→ 揭示：成为真实证明
→ 余波：改变关系或主题意义
```

### 12. 揭示后立即行动

真相不是奖励读者的说明段。揭示应立刻改变：

- 谁追谁；
- 谁信谁；
- 谁承担责任；
- 目标和路线；
- 公开身份；
- 生死或政治代价。

没有行动后果的真相只是一则背景知识。

## 八、公平误导原则

### 1. 前文事实不可作假

焦点人物没看见的内容可以不写，但已经明确写出的客观事实不能在揭示时随意取消。

### 2. 解释可以错，感知应尽量真

推荐：

```text
他看见A，听见B，因此以为C。
```

后文揭示A、B仍然是真的，只是C不完整。

### 3. 至少保留一条异质线索

主假设成立时，仍留下一个不完全吻合的细节。它不必足以破解真相，但应在回看时显得公平。

### 4. 误判必须符合人物

- 忠厚者可能过信承诺；
- 骄傲者可能低估弱者；
- 多疑者可能高估阴谋；
- 专家可能把陌生问题套入熟悉模型；
- 有愧者容易把中性信号理解为指责。

### 5. 不靠语法作弊

若焦点人物明确知道凶手是谁，不能在他的内心反复用“那个人”躲避名字，只为不让读者知道。

### 6. 揭示应提高解释力

新答案应同时解释多项旧细节，比旧假设更简单、更完整，而不是依赖突然出现的新人物或新规则。

## 九、线索生命周期

为重要线索设计六个阶段：

```text
1. 植入：作为自然场景细节出现
2. 注意：某人物因自身偏好看见它
3. 解释：被赋予暂时意义
4. 变义：新证据使旧解释不稳
5. 证明：与其他线索合拢
6. 后果：改变行动、关系或价值判断
```

### 线索类型

| 类型 | 作用 | 风险 |
|---|---|---|
| 身份线索 | 证明某人是谁 | 单一胎记式证据过于便利 |
| 行动线索 | 证明谁做过什么 | 能力相同不等于实际实施 |
| 时间线索 | 排除或确认在场可能 | 行程必须与时间线一致 |
| 物件线索 | 连接人物与现场 | 可被偷放、转赠或伪造 |
| 语言线索 | 暴露知识、口音、称谓 | 需符合人物声口和语言能力 |
| 规则线索 | 用门派、礼法或职业知识解释 | 不可临揭示才新增规则 |
| 缺席线索 | 应有之物或行为没有出现 | 必须先建立“本来应有” |
| 关系线索 | 动机、保护、回避、异常称谓 | 动机不能单独证明行为 |

## 十、揭示阶梯

不要把谜底一次讲完。按需要使用：

```text
L1 异常：有东西不对
L2 假设：人物提出最可能解释
L3 支持：新证据提高置信度
L4 裂缝：出现不能完全解释的细节
L5 重构：换一个问题或因果模型
L6 证明：独立证据互相印证
L7 公开：真相进入人物关系或社会场域
L8 代价：人物必须因真相行动
```

短谜团可以合并层级；长篇核心秘密应多次变义，但每次都要有实质进展。

### 揭示方式

- 人物自行推理；
- 证人回答精确问题；
- 物件与旧记忆相认；
- 行动逼迫隐藏者暴露；
- 多个持有人交换信息；
- 谎言内部出现矛盾；
- 旧场景在新视角下重演。

纯粹由反派长篇坦白，只适合他有明确炫耀、交易、拖延或威慑目的时。

## 十一、人物误判系统

为主要人物维护：

```yaml
cognition:
  expertise: []               # 哪些领域判断可靠
  blind_spots: []             # 看不见或不愿看见什么
  default_trust:              # 默认信人、信制度、信证物还是信自己
  evidence_preference: []     # 亲见、口供、物件、逻辑、权威、直觉
  wish_bias: []               # 希望什么是真的
  fear_bias: []               # 最怕什么是真的
  identity_bias: []           # 身份、门派、阶层造成的先入判断
  confidence_style:           # 谨慎概率化或迅速绝对化
  admission_style:            # 发现判断错后如何承认
  secrets_kept: []
  secrets_suspected: []
  unknown_unknowns: []
```

聪明人物的误判应来自：

- 数据被有意设计；
- 专业领域之外；
- 情感利益太强；
- 时间压力；
- 正确推理建立在一个隐藏的错误前提上。

不要让聪明人物为剧情突然忘记常识。

## 十二、对白中的信息交易

对白不是搬运背景，而是控制谁获得多少信息。

### 每句话的三层

```text
字面信息：说了什么
来源声明：凭什么知道
关系动作：为何对你说、为何现在说
```

### 常见信息策略

- 先给可验证小事实换取信任；
- 只回答问题中最窄的一部分；
- 用真话诱导错误结论；
- 询问对方本不该知道的细节；
- 假装知道更多，观察对方反应；
- 故意说错一处，测试谁会纠正；
- 公开场合说给第三人听；
- 用称谓证明关系或身份；
- 拒答，从而暴露问题确有价值。

### 询问弱证人

不要先问“谁是凶手”，而要问：

1. 你看见什么？
2. 当时站在哪里？
3. 先发生什么，后发生什么？
4. 哪部分是别人告诉你的？
5. 你为什么认为那个人是谁？

将感知和解释拆开，才能获得可用证词。

## 十三、长篇信息节奏

### 一章至少完成一种变化

- 新增事实；
- 旧事实被新人物知道；
- 旧线索获得新解释；
- 错误信念置信度上升；
- 秘密被部分公开；
- 证据被破坏或转移；
- 读者领先人物；
- 人物终于追上读者。

### 问题栈

同时维护三层问题：

```text
即时问题：这一场如何脱身、取物、说服
章节问题：此人是否可信、线索指向哪里
长篇问题：身份、旧案、核心承诺的真相
```

每解决一个问题，最好打开或加深另一个问题。不能只开不收，也不能一章把所有层级清空。

### 答案与代价配对

获得重要信息应有代价：

- 暴露位置；
- 欠下人情；
- 伤害信任；
- 失去证人；
- 让敌人知道自己在调查；
- 必须立即作出选择。

免费答案容易显得作者喂信息。

### 事实表

```yaml
  evidence: []
  evidence_that_can_be_faked: []
  current_public_version:

```

### 人物认知表


## 十五、AI生成流程

### 第一步：写后台真相

用一句不含悬念措辞的话写清客观事实。作者自己不清楚真相时，无法设计公平线索。

### 第二步：建立场景前认知表

列出每位在场人物：

- 知道；
- 怀疑；
- 误信；
- 隐瞒；
- 不知道。

另列读者当前状态。

### 第三步：确定本场信息任务

一场最多选择一至两个主要任务：

- 植入线索；
- 强化误判；
- 制造裂缝；
- 完成局部揭示；
- 让秘密换持有人；
- 让读者领先；
- 让人物追上。

### 第四步：选择可感知证据

证据必须能被当前焦点人物从当前位置获得。记录感官、遮挡、来源和是否完整。

### 第五步：让人物解释

根据其专业、盲点、愿望和恐惧形成带置信度的判断。判断不必正确，但要是此人当下最经济的解释。

### 第六步：安排公开策略

人物是说真话、说一半、撒谎、试探、沉默，还是先行动？对白服从人物利益。

### 第七步：制造行动后果

让认知改变路线、联盟、风险、目标或关系。不要以“众人恍然大悟”结束。

### 第八步：回写账本

更新事实证据状态、每个角色的信念、读者问题栈以及下一次计划重释的位置。

## 十六、改写与诊断

### 把作者解释改成认知过程

原始写法：

> 他不知道信是伪造的，因此误会了师弟。

改写步骤：

1. 给出信中一至两条真实可验证信息；
2. 让人物识别自己熟悉的纸张或口吻；
3. 留下一处暂未注意的异质细节；
4. 让人物根据关系偏见形成结论；
5. 立刻按结论采取有代价的行动。

原创示例：

> 纸是山中自造的，末尾那句训诫也确是师父常说。他把信折起，只当师弟终于露了本心，没有留意封口的朱印比本门印泥淡了一层。

### 七问诊断

1. 后台客观事实是否写得清楚？
2. 当前焦点人物凭什么获得这条信息？
3. 感知事实与人物解释是否分开？
4. 误判是否由真实证据和人物盲点共同产生？
5. 读者此刻应领先、同步还是落后？
6. 揭示能否解释此前多项细节？
7. 信息变化是否造成行动或关系后果？

### 回看测试

在知道真相后重读此前场景：

- 客观描写是否仍然成立？
- 至少一条线索是否获得新意义？
- 是否能理解人物为何误判？
- 是否存在作者故意避开自然想法的语法作弊？
- 新答案是否比旧答案解释更多？

## 十七、常见失败

### 1. 作者藏牌

焦点人物明确知道答案，叙述却用模糊代词回避。修正：换焦点人物、改为外部视角，或让知情者确有不去想它的现场任务。

### 2. 人物突然变笨

忽略近在眼前的证据，只为延长秘密。修正：让证据不完整、被更强证据遮蔽，或给人物明确偏见与时间压力。

### 3. 假线索事后取消

揭示时宣布前文看到的东西其实不存在。修正：保留事实，只重释来源、动机和因果。

### 4. 新证据空降

关键物件、证人或规则在揭示前从未出现。修正：提前自然植入，至少让读者知道其存在和适用范围。

### 5. 全知叙述提前泄密

叙述者随手解释反派动机，后面人物仍当谜团调查。修正：明确读者领先是否有悬念收益，否则保留到证据出现。

### 6. 内心独白撒谎

人物独处时故意用假想法欺骗读者，却没有自欺依据。修正：可以隐瞒行动细节，不可让内心陈述与真实认知矛盾。

### 7. 聪明等于全知

人物从一条普通线索推出完整真相。修正：建立证据链、领域能力和备选解释，并让结论具有置信度。

### 8. 误会只靠不说话

一句解释便能解决，双方却无理由拖延。修正：增加说出真相的代价、关系不信任，或让双方各自掌握不完整事实。

### 9. 反派讲解全部计划

没有利益却向敌人完整复盘。修正：揭示应来自逼问、证据合拢、行动暴露，或反派明确的交易与威慑。

### 10. 谜底没有后果

众人知道真相后继续原计划。修正：让揭示改变责任、联盟、目标、危险或人物自我认识。

### 11. 问题只开不收

不断增加神秘人和秘密，却没有阶段答案。修正：维护问题栈，每章至少关闭或实质推进一个问题。

### 12. 知识账本膨胀

追踪所有世界设定，实际写作无法使用。修正：只记录会改变人物选择、关系和情节的信息。

## 十八、可直接交给AI的指令

```text
设计或检查信息差时，分别维护客观事实、人物认知、人物公开说法和读者认知，不能把它们混为一谈。

1. 先用一句话写清后台真相，再决定哪些内容暂不公开。
2. 每条信息标明来源：亲历、亲见、实物、转述、传闻、推断或直觉，并记录可信度。
3. 让人物从实际位置和感官获得证据；看不见、听不懂或不在场的信息不得无故进入其认知。
4. 严格区分感知事实与人物解释。误判应由两条以上真实证据，加人物盲点、愿望、恐惧或知识缺口形成。
5. 前文客观事实不可在揭示时取消；只能重释来源、动机、归属或因果。
6. 明确读者此刻是领先、同步还是落后于人物，并确保这种位置产生具体张力。
7. 重要线索依次经历植入、注意、解释、变义、证明和后果；揭示应同时解释多项旧细节。
8. 对白按信息交易组织：完整真话、部分真话、真话误导、试探、拒答或有目的的谎言。
9. 每场只承担一至两个主要信息任务，并让信息变化立即改变行动、关系、目标或风险。
10. 场景结束后更新人物知识账本、读者问题栈和线索状态，防止后文知识穿帮。
```
