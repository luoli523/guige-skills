# 文化素材来源登记

这里登记项目实际查阅或准备核验的来源。只保存书目信息、定位方式和判断，不复制整篇受版权保护的内容，也不记录账号、密钥或其他访问凭据。

## 登记原则

- 优先记录能定位到篇章、页码、条目或稳定页面的来源。
- 来源权威不等于其中每个解释都无争议；将不同版本和分歧写入对应素材卡。
- 民间传说可以由地方志、民俗调查或地方文化机构证明“有此流传”，但不能因此自动证明传说事件真实发生。
- 二手网页适合发现关键词和书目线索；重要年代、制度与礼俗尽量回到更可靠来源核验。
- 同一来源可以支持多张素材卡，使用稳定 `Source ID` 引用，避免重复抄写书目信息。
