# 文化素材候选池

这里暂存尚未成为作品事实的典故、习俗、传说和地域风物。候选可以来自模型已有知识、用户记忆、阅读线索或外部搜索；本文件不是正式素材清单，也不是 AI 只能使用的白名单。

## 开放调用规则

1. 构思时先查看已有候选和 `reference-manifest.md`，但允许提出库外材料。
2. 模型仅凭已有知识提出的具体史实，默认标为 `unverified`，不得直接写进世界设定或当作确定事实。
3. 真实文化候选只有在确认时代、地域、适用人群和来源边界后，才建立独立素材卡并标为 `verified`。
4. 用户确认用于故事后，再将素材卡标为 `adopted`，并登记到 `reference-manifest.md`。
5. 为剧情有意变形时标为 `adapted`；纯虚构而借用真实文化质感时标为 `invented`。`invented` 不伪造来源，经过世界规则检查和用户确认后可以直接采用。
6. 未采用、被否决或发现不合时代的候选可以标为 `rejected`，保留简短原因，避免以后重复误用。

## 候选转正检查

- 是否能定位至少一个来源？
- 来源证明的是史实、争议说法、传说存在，还是文学表达？
- 年代、地域和使用人群是否与本作相符？
- 哪个具体人物有理由知道或误解它？
- 它是否会改变行动、关系、判断、风险或主题？
- 是忠实使用，还是需要明确标记艺术加工？

通过后，复制 `material-card.md` 建立独立素材卡；没有实际叙事用途的知识不必转正。
