# 武侠小说项目使用指南

这是一部具体小说的长期工作档案。你不需要记住每个文件的用途，也不必手工维护全部内容；只要告诉 AI 你现在想做什么，并让它使用 `$guige-wuxia-writing` 管理本目录。

本文是一分钟速查页。需要了解完整能力地图、全书工作流、章节生产流程、项目文件协同与常见误用时，请阅读 [01-写作最佳实践.md](01-写作最佳实践.md)。

## 只记住这一句话

```text
使用 $guige-wuxia-writing，以当前目录为小说项目，帮我完成【当前任务】，并把需要长期保存的变化同步回项目文件。
```

把【当前任务】换成你眼下想做的事情即可。

## 最常用的六句话

### 1. 第一次开始

```text
使用 $guige-wuxia-writing，以当前目录为小说项目。通过一次只问我一个问题的方式，帮助我确定故事核心；确认后更新项目文件。
```

### 2. 设计故事总纲

```text
读取当前项目已有设定，给我三个不同的故事主线方案。先讨论，不要立即写正文。
```

### 3. 创建或完善人物

```text
帮我设计【人物名】，重点完善他的欲望、冲突义务、知识边界和专属声口；确认后更新人物卡及人物关系。
```

### 4. 规划下一章

```text
根据当前总纲和最新状态规划下一章，列出场景目标、阻力、关键选择、信息变化和章末牵引；保存章节计划。
```

### 5. 写正文

```text
读取下一章计划和相关人物资料，创作本章正文。完成后检查视角、声口、节奏与连续性，并保存到 drafts。
```

### 6. 写完一章后整理

```text
检查刚完成的章节，把时间、行程、伤势、人物认知、关系变化、物件去向和伏笔状态同步回项目档案。
```

## 其他常见请求

### 改写已有文字

```text
诊断并改写【文件或段落】。保留事实、人物动机和情节结果，重点改善【节奏／对白／景物／武打／古雅程度】。
```

### 只诊断，不改写

```text
诊断【文件或段落】，按“症状—证据—影响—修改建议”输出。先不要改写正文。
```

### 加入典故、风俗或地域材料

```text
为【场景】寻找适合的【典故／习俗／传说／地域风物】用法。先说明它怎样影响人物行动或冲突，确认后再写入并登记素材。
```

### 改善幽默与情绪张弛

```text
诊断【章节或场景】的诙谐机制和情绪换挡。检查笑点是否属于人物、是否推进任务、转调是否有具体铰链；先给修改方案，不要立即重写。
```

### 设计或检查重要物件

```text
追踪【物件名】的完整生命周期。检查它的物理规则、位置、持有人、正当归属、知情者、转手、状态变化、变义与最终回收，并同步物件账本、知识账本和时间线。
```

### 设计人物、门派、武学或章回名称

```text
为【人物／门派／武学／地点／器物／章节】设计命名。先从世界生活与文化中建立语义场，再给出不同命名来源的方案；检查命名者、机制映射、阵营区分、读音字形碰撞与后续变义，确认后同步 `naming-system.md`。
```

### 不知道下一步做什么

```text
检查当前项目完成度和明显矛盾，只告诉我现在最值得完成的一件事，并带我做完。
```

## AI 会在后台维护什么

| 内容 | 保存位置 |
|---|---|
| 故事核心与主题 | `premise.md` |
| 全书主线与伏笔 | `story-outline.md` |
| 年代、地域和世界规则 | `world.md` |
| 人物、门派、武学、地点和章名的语义网络 | `naming-system.md` |
| 人物资料与说话方式 | `characters/` |
| 人物之间的关系变化 | `relationships.md` |
| 时间、行程和伤势 | `timeline.md` |
| 重要物件、秘密与线索 | `objects-and-clues.md` |
| 谁知道、怀疑或误信什么 | `knowledge-and-beliefs.md` |
| 典故、风俗和历史素材 | `reference-manifest.md` |
| 每章开写前的设计 | `chapter-plans/` |
| 正文 | `drafts/` |

你通常不必指定更新哪个文件。只要在请求结尾加上：

```text
把需要长期保存的变化同步回项目文件。
```

## 三条使用原则

1. **先讨论，后落稿**：方案未确定时明确说“先讨论，不要写正文”。
2. **一次只推进一层**：先故事核心，再总纲，再章节计划，最后正文。
3. **每章结束做同步**：这是避免几十章以后人物认知、伤势和伏笔互相矛盾的关键。
