# 命名与语义网络

这里只登记需要跨章节保持一致、能够显示身份关系或参与叙事回收的专名。一次性普通人物、日用品和过路地点不必全部入账。

## 全局命名原则

- 本作最重要的历史、地域与生活语义源：
- 各文化共同体分别由谁命名：
- 全书共享的主题词场：
- 高频幻想字预算与禁用组合：
- 外族名、音译名和异体写法规范：
- 生僻字与首次释义原则：

## 同步提醒

- 人物新增、放弃或恢复本名、法号、绰号、官称与化名：同步对应人物卡和 `relationships.md`。
- 地名或器物异名参与线索：同步 `knowledge-and-beliefs.md`；器物换名同时核对 `objects-and-clues.md`。
- 组织、地域或时代的命名权发生变化：同步 `world.md` 与 `timeline.md`。
- 确定章名后：同步对应 `chapter-plans/`。
