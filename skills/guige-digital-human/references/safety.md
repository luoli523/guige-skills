# Safety & Authorization

## 使用前提

只用于已获授权的声音、肖像、文案和发布场景。开始克隆或生成前，向用户确认：

- 声音样本的本人已同意声音被克隆并用于该用途。
- 人像照片的本人已同意肖像被用于数字人视频。
- 文案内容有权使用（原创或已授权）。
- 最终用途（平台、商用与否）在授权范围内。

任何一项不确定就停下，让用户先补齐授权，不要"先做出来再说"。

## 不做的事

- 不克隆公众人物、他人声音用于仿冒或误导。
- 不生成冒充真实人物发言的内容。
- 不提供法律意见。涉及合规披露、生物特征数据、平台政策（如 AI 生成内容标注要求）时，提示用户在发布前自行核实适用规则。

## 数据与密钥

- API key 只从 guige-scoped `.guige-skills/.env` 读取，不落地到 state 文件、日志或输出。
- 不打印 Authorization header 和签名临时下载 URL。
- 声音样本、人像、生成视频属于用户私有素材，只存在任务目录内，不进 git、不进 skill 包。

## 公开分发

把本 skill 打包分发时只包含 `SKILL.md`、`references/`、`scripts/`。不打包 `.env`、真实素材、job-state 文件、生成视频、签名 URL。用户需自带 MiniMax / HeyGen 账号、计费与素材授权。
